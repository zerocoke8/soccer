# 배경 그림 (7장)

2026-10-05 · 브랜치 `outgame-lesson` · Codex CLI (`gpt-6-astra`, xhigh) · 1536×1024 PNG (가로). 기획: `docs/LESSON_PROTO_PLAN.md` §24.12.5.
그림체는 선수 일러스트와 같다 ([../characters/README.md](../characters/README.md)). 확정 두 장 (`silluen.png` · `neria.png`) 을 **배경 그리는 법 참고로만** 넣어 그렸다 (사람은 그리지 말라고 적음).

- **사람 · 동물 없이 배경만** 그린다. 사람은 확정 일러스트를 잘라 (`img/portraits/`) 화면에서 겹친다 — 한 장에 여러 명을 그리면 확정 외형이 어긋나기 쉽다.
- 글자 · 숫자 · 로고 · 문장 · 무늬 있는 깃발 · 간판 글씨 없음. 깃발 · 천은 한 가지 색.
- 가운데 왼쪽은 흉상 · 글 상자가 올라갈 자리라 하늘 · 잔디 · 벽처럼 단순하게 비우고, 볼거리는 오른쪽 · 가장자리에 둔다.
- 화면용은 `img/scenes/<id>.webp` (1280×853, 품질 0.8, 85 ~ 164KB, 7장 약 0.9MB). 명세 `art/portraits.json` 의 `scenes` → `node tools/portraits.mjs --only title,ground,clubhouse,town,stands,nature,onsen` (Chrome 필요) 이 WebP 와 `data/portraits.json` 을 다시 만든다.
- 프롬프트는 [prompts/](prompts/) (`<id>.txt`, 첫 줄 `$imagegen`) — 앞 절반 (그림체 · 세계 · 구도 · 금지) 은 7장이 같고 SCENE · Palette 줄만 다르다.
