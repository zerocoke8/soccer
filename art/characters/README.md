## 그림체 (기획자 확정)

- **2D TV 애니메이션 원화 느낌의 셀 채색**: 고른 굵기의 또렷한 선, 기본색 + 경계가 딱 떨어지는 그림자 1단계 (차가운 청보라), 광택 없는 피부와 볼터치, 덩어리로 칠한 머리카락에 하이라이트 몇 줄, 그라데이션 홍채의 애니 눈, 테두리 빛, 평평하게 빛나는 원소 효과, 하늘 그라데이션 + 평평한 실루엣의 단순한 배경.
- 기준 그림: 외부 레퍼런스 (엘프 궁수, 커밋하지 않음 — `.gitignore` 의 `reference*.png`) + 확정된 두 장 `silluen.png` · `neria.png`. 나머지 14장은 이 세 장을 함께 넣어 그렸다.
- 거절된 방향: 매끈한 광택 · 그라데이션 칠 ("채색이 아예 다르다"), 블루 아카이브풍 파스텔 (덜 좋음).
- 구도: 카메라는 눈높이 ~ 살짝 위 (아래에서 올려다보는 구도는 다리가 너무 커진다). 발차기처럼 손발 오류가 잦은 동작은 피하고 서 있는 포즈.
- 캐릭터 규칙: 전원 성인 여성. 장신 = 성숙한 체형 (절제), 단신 = 어려 보이는 인상 · 체형 강조 없음. 선수마다 원소 색 축구 유니폼, 원소에 맞는 배경.
