## 2. 레퍼런스에서 가져올 것 / 버릴 것

### 2.1 우마무스메 → 육성 뼈대

| 원작 | 우리 게임 |
|---|---|
| 턴제 훈련 5종 중 택1 | 동일. 단, 칸을 고르면 **그 칸에 모인 선수들**이 훈련한다 |
| 서포트 카드 6장, 훈련 칸에 랜덤 등장 | 동일 (일러스트 카드, 필드에는 서지 않음) |
| 우정 훈련 | 동일 |
| 체력 / 의욕 / 실패율 | 선수별 체력 / 팀 컨디션 / 부상 |
| 목표 레이스 미달 시 육성 종료 | **패배해도 계속**, 평가 상한과 보상만 하락 |
| 인자 계승 | OB 코치 (등록된 선배 선수의 인자) |
| 팀 경기장 (비동기 PvP) | 아레나 |

버리는 것: 1시간짜리 육성, 지켜보기만 하는 레이스, 한 명만 키우는 구조

### 2.2 사커스피리츠 → 경기 전투

| 원작 | 우리 게임 |
|---|---|
| 라인 돌파 턴제 경기 | 7인제 라인 돌파 듀얼 |
| 공격 선택 vs 수비 선택 | 드리블/패스/슛 vs 태클/인터셉트/블록 |
| 원소 속성 | 원소 5종. 상성 판정이 아니라 **팀 공명 보너스**와 스킬 플레이버 |
| 액티브 스킬, 컷인 | 도트 컷인 필살기 (SSR) |
| 팀 편성 시너지 | 원소 공명 + 종족 패시브 + 팀워크 |
| 자동 전투 + 수동 개입 | 동일 |

버리는 것: 장비 강화 체계, 행동력 과금, 5각 상성 판정

### 2.3 로그라이크 → 런 구조

- 런마다 달라지는 훈련 배치, 이벤트, 상대 팀, 유물, 루트
- "실패하면 처음부터"는 없다. 대신 **매 런이 다르고, 결과물(팀 평가)로 경쟁하며, 플레이로 영구 해금**되는 것을 로그라이크의 축으로 삼는다
- 상대 의도 표시, 유물, 시즌 사이 루트 선택, 리그 등급(난이도 단계)

## 3. 디자인 기둥

1. **한 턴에 팀 전체를 굴린다** — 어느 칸을 고르느냐가 "누구를 키우고 누구와 친해지느냐"를 동시에 정한다. 7명이지만 결정은 한 번.
2. **경기는 수읽기 싸움, 자동으로도 충분하다** — AI가 전술 지시대로 뛰고, 원하면 결정적 포제션에만 개입한다. 수동이 유리한 폭은 작게.
3. **매 런은 다르고, 팀은 남는다** — 런 결과물이 곧 PvE·PvP 팀. 20분 한 판이 엔드게임으로 이어진다.
4. **도트로 살린 종족과 원소** — 작은 스프라이트, 표정 풍부한 초상화, 종족·원소가 한눈에 읽히는 색과 실루엣.

## 4. 세계관

### 4.1 설정

- 대륙 이름 **미정**. 대전쟁 끝에 모든 종족이 **전쟁 금지 조약**을 맺었다.
- 국경과 자원 분쟁은 전쟁 대신 공식 경기 **경계전(境界戰)** 으로 결정한다. 이기면 영토와 명예, 지면 양보.
- 각 나라·종족은 대표 클럽을 두고, 조약 리그가 경계전 일정을 관리한다.
- 플레이어는 **신생 클럽의 감독**. 왜 신생 클럽을 맡게 됐는지(스토리 훅)는 미정.
- 런의 세 시즌 = 지방 조약 리그 → 종족 연맹컵 → 대륙 경계전. 각 시즌 끝의 목표 경기가 경계전이다.

### 4.2 원소 (5종) **[가정]**

| 원소 | 이미지 | 팀 공명 보너스 (같은 원소 3명 이상 편성 시) |
|---|---|---|
| 불 | 공격적, 폭발력 | 슛 위력 +5% |
| 물 | 유연, 지구력 | 경기 체력 소모 −10% |
| 바람 | 연계, 속도 | 패스 성공률 +5% |
| 대지 | 견고, 수비 | 수비 판정 +5% |
| 번개 | 순간, 텐션 | 텐션 획득 +20% |

- 4명 이상이면 보너스 1.5배. 원소는 **상성 판정에 쓰지 않는다** (판정은 8.3절의 3스타일).
- 원소는 스킬 이펙트·컷인 색·캐릭터 성격에 반영. 편성 목표(공명)를 주어 가챠 캐릭터 수집에 이유를 만든다.

### 4.3 종족 **[가정]**

| 종족 | 스탯 성향 | 종족 패시브 예시 |
|---|---|---|
| 인간 | 균형, 성장률 높음 | 훈련 효율 +5% |
| 엘프 | 패스·테크닉 | 패스 실패 시 50% 확률로 공 유지 |
| 드워프 | 수비·피지컬 | 블록 시 슛 위력 추가 −10% |
| 수인 (늑대·고양이·토끼 등 계열) | 스피드·드리블 | 드리블 성공 시 체력 소모 −20% |
| 정령족 (원소의 화신) | 원소 스킬 강화, 체력 낮음 | 원소 공명 보너스 +50% (본인 원소만) |
| 거인족 | 파워·블록, 스피드 낮음 | 몸싸움 판정 +15% |

- 종족 목록과 수는 런치 캐릭터 20명에 맞춰 조정. 6종 × 3~4명 정도.
- 종족 = 실루엣과 색의 차이. 도트에서 한눈에 구분되어야 한다 (수인의 귀·꼬리, 거인의 크기 차이 등).

### 4.4 감독 (플레이어)

- 이름 설정 가능. 초상화 없음 **[가정]**. 이벤트는 감독 ↔ 선수·서포트 대화 형식.
- 감독의 역할은 훈련 칸 선택, 전술 지시, 스킬 부여, 경기 개입.

## 5. 코어 루프

```
[클럽 로비]   스쿼드 7명 편성 (GK1·DF2·MF2·FW2) + 서포트 카드 6장 + OB 코치 2명 + 리그 등급 선택
                  │
[런 · 20분]   시즌1 (8턴) → 경계전1 → 루트 선택
                  → 시즌2 (8턴) → 경계전2 → 루트 선택
                  → 시즌3 (8턴) → 대륙 경계전 (결승)
                  │
[결과]        팀 평가 G~S → 팀 등록 (슬롯 저장) + 클럽 포인트 + 선수 명부 갱신
                  │
[엔드게임]    챌린지 리그 (PvE 단계) / 아레나 (비동기 PvP)  ← 등록 팀 + 전술 지시로 자동 경기
                  │
                  └──► 클럽 포인트로 해금 → 다음 런 (더 높은 리그 등급, 새 유물·이벤트)

[턴 루프]     칸 배치 확인 (선수·서포트 위치, 체력) → 행동 선택 → 결과 · 이벤트 → 다음 턴
```

## 6. 런 구조

| 구간 | 턴 | 목표 경기 | 비고 |
|---|---|---|---|
| 시즌 1 · 지방 조약 리그 | 8 | 경계전 1 (8포제션) | 유대·팀워크 쌓기 |
| 시즌 2 · 종족 연맹컵 | 8 | 경계전 2 (10포제션) | 중간에 합숙 이벤트 |
| 시즌 3 · 대륙 경계전 | 8 | 결승 (12포제션) | 보스 팀 |

- 총 24턴 + 목표 경기 3회 + 선택 경기(친선전) 0~2회.
- **목표 경기 패배 시:** 런은 계속. 그 시즌 보상(유물 선택지, 스킬 포인트) 감소. 최종 평가 상한 하락: 3승 = S 가능 / 1패 = A 상한 / 2패 = B 상한 / 3패 = C 상한 **[가정]**.
- 패배해도 다음 시즌 상대 난이도는 그대로. 봐주기 없음.

**시즌 사이 루트 선택** (3갈래 중 1):

| 루트 | 효과 |
|---|---|
| 명문 캠프 | 다음 시즌 훈련 효율 +20%, 부상률 +5%p |
| 원정 | 고난도 친선전 1회 강제, 승리 시 희귀 유물 |
| 온천 휴양 | 전원 체력·컨디션 완전 회복, 확정 이벤트 1회 |

**시간 예산 (자동 진행 기준)**

| 항목 | 시간 |
|---|---|
| 24턴 × 약 20초 | 8분 |
| 목표 경기 3회 × 약 1분 (자동) | 3분 |
| 이벤트 · 루트 선택 · 결과 화면 | 5분 |
| 합계 | 약 16~18분 → 여유 포함 20분 |

수동 개입을 자주 하면 25분 안팎. 중간 저장은 매 턴 자동. **[검증]** 20분에 실제로 끝나는가.

## 7. 육성 시스템

### 7.1 스탯

| 스탯 | 경기에서 쓰이는 곳 | 주 스탯인 포지션 |
|---|---|---|
| 슈팅 | 슛 위력 | FW |
| 드리블 | 드리블 돌파 | FW, MF |
| 패스 | 패스 성공, 연계기 위력 | MF |
| 수비 | 태클·인터셉트·블록, GK 세이브 | DF, GK |
| 피지컬 | 경기 체력 소모 감소, 몸싸움, 블록 | DF, GK |

- 범위 0~1000 **[가정]**, 등급 G~S. 화면에는 포지션별 주 스탯 2개를 크게, 나머지는 작게.
- 초기 스탯은 레어도·돌파로 결정 (10.1절). 런 동안의 성장은 모두 훈련.

### 7.2 훈련 칸 — 팀 동시 육성의 핵심 ★

- 매 턴, 훈련 칸 5개(슈팅·드리블·패스·수비·피지컬)에 **선수 7명과 서포트 카드 6장이 랜덤 배치**된다.
  - 선수 배치는 포지션 성향 가중 (FW는 슈팅·드리블 칸 확률↑, GK는 수비·피지컬↑). 그래도 가끔 엉뚱한 칸에 간다.
- 감독은 칸 **하나**를 고른다.
  - 그 칸의 선수 전원: 주 스탯 大 + 부 스탯 小 상승, 체력 소모. 체력이 낮은 선수는 개별로 실패·부상 판정.
  - 그 칸의 서포트 카드: 훈련 효율 보너스, 유대 상승. 유대 80 이상이면 **우정 훈련** (효율 대폭 상승).
  - 다른 칸의 선수: 자율 훈련 (효율 20%, 체력 소모 없음) **[가정]**.
- 감독의 한 번의 선택 = "이번 턴 누구를 키울까 + 어느 서포트와 유대를 쌓을까 + 누구를 쉬게 할까".
- 칸 위에는 선수·서포트 얼굴 아이콘과 예상 상승치를 표시. 좋은 칸(선수 3명 + 우정 훈련 서포트)이 보이면 고민이 생긴다.

**[검증]** 7명의 배치를 한 화면에서 읽을 수 있는가. 선택이 매 턴 고민되는가.

### 7.3 턴 행동

| 행동 | 효과 |
|---|---|
| 훈련 (5칸 중 1) | 7.2절 |
| 휴식 | 전원 체력 회복, 컨디션 회복 확률 |
| 외출 | 팀 컨디션 상승, 서포트 이벤트 발생 |
| 전술 미팅 | 팀워크 상승, 전술 지시 변경, 스킬 구매 |
| 친선전 | 스킬 포인트·유물 기회, 전원 체력 소모 큼 |

### 7.4 체력 · 컨디션 · 부상 · 팀워크

- **체력** 선수별 0~100. 50 미만부터 훈련 실패율 상승. 실패 시 부상 (스탯 하락, N턴 결장 → 그 자리는 스탯 낮은 대체 선수).
- **컨디션** 팀 단위 5단계 **[가정]**. 훈련 효율 −20% ~ +20%, 경기 스탯 보정. 선수별 컨디션은 UI 부담이 커서 팀 단위로 시작.
- **팀워크** 0~100. 같은 칸에서 함께 훈련한 횟수, 전술 미팅, 이벤트로 상승. 경기의 패스 성공률 보정과 **연계기 해금** (팀워크 60 / 80 / 100).

### 7.5 서포트 카드 (우마무스메 방식)

- 런 시작 시 6장 편성. 훈련 칸에 랜덤 등장하고 필드에는 서지 않는다.
- 카드 타입 = 훈련 종류 (슈팅/드리블/패스/수비/피지컬) + 만능. 타입 칸에 등장할 확률이 높다.
- 효과: 훈련 효율, 초기 유대, 스킬 힌트 확률, 고유 효과 (예: "이 카드와 우정 훈련 시 부상률 0").
- 유대 0~100. 80 이상 우정 훈련. 유대 구간별 서포트 이벤트 (스킬 힌트, 스탯, 스토리).
- 카드의 정체(세계관): 선수 캐릭터의 다른 일러스트 + 코치·감독·전설의 OB 등 NPC **[가정]**. 선수 캐릭터를 카드로도 쓰면 캐릭터 디자인 수를 늘리지 않고 카드 풀을 채울 수 있다.

### 7.6 이벤트

- 종류: 선수 이벤트 (선수별 스토리, 런당 2~3개), 서포트 이벤트 (유대 구간), 랜덤 이벤트, 시즌 이벤트 (경계전 전후), 루트 이벤트.
- 감독 시점의 대화. 2~4줄, 선택지 있으면 2개.
- **리스크 이벤트** (로그라이크 재미)
  - "비밀 특훈": 선수 1명 드리블 +40, 50% 확률로 부상
  - "스카우트의 유혹": 희귀 유물을 얻는 대신 서포트 1장 이탈 (남은 시즌 동안)
  - "정령의 계약": 원소 공명 보너스 2배, 대신 그 원소 외 선수 체력 −10/턴

### 7.7 스킬

| 종류 | 방식 | 예시 |
|---|---|---|
| 액티브 | 텐션 소모. **AI 발동 조건 내장** (수동 개입 시 직접 선택도 가능) | "라인 브레이커": 드리블 성공 시 한 라인 추가 전진 |
| 패시브 | 조건 충족 시 자동 | "막판 집중": 마지막 2포제션 슈팅 +15% |
| 고유 필살기 | SSR 선수 1개, 도트 컷인. 돌파로 레벨 상승 | — |

- 습득: 힌트 (서포트 이벤트·우정 훈련) → 팀 스킬 포인트로 구매 → 특정 선수에게 부여. 힌트 레벨만큼 할인.
- 모든 액티브 스킬은 "언제 쓸지"가 정의되어 있어야 한다. 수동을 나중에 빼도 스킬 시스템이 남는다.

### 7.8 전술 지시 ★ (런과 PvP를 잇는 장치)

감독이 전술 미팅에서 설정하고, 등록 팀에 함께 저장되어 PvE·PvP 자동 경기에서 쓰인다.

| 항목 | 선택지 |
|---|---|
| 공격 성향 | 드리블 위주 / 균형 / 패스 위주 |
| 슛 타이밍 | 라인 다 뚫고 / 기회 보이면 중거리 |
| 수비 성향 | 태클 선호 / 균형 / 인터셉트 선호 / 의도 따라가기 |
| 텐션 사용 | 아끼기 / 즉시 / 결승골 상황만 |
| 공격 시작 | 특정 선수 지정 (킥오프·역습 시 첫 공 소유자) |

- 수동 개입 = 이 지시를 **한 포제션만** 덮어쓰기.
- 전술 슬롯은 클럽 레벨로 늘어남 (프리셋 저장).

## 8. 경기 시스템

### 8.1 기본 규칙

- 7인제: GK 1 · DF 2 · MF 2 · FW 2. 포메이션 변경 가능 (3-1-2 등).
- 경기 = N포제션 (일반 8, 목표 8/10/12). 수비 성공 시 공을 뺏은 팀이 그 라인에서 역습.
- 공격 경로: 빌드업 → 상대 FW 압박 돌파 → 상대 MF 돌파 → 상대 DF 돌파 → 슛 vs GK.
- 한 라인 돌파 = 공 가진 선수 vs 그 라인 수비수 1명의 듀얼.
- 교체 없음 **[가정]** → 피지컬 스탯의 가치.

### 8.2 듀얼

| 공격 | 스탯 | 성공 시 | 약한 수비 |
|---|---|---|---|
| 드리블 | 드리블 | 같은 선수가 다음 라인으로 (체력 소모 큼) | 태클 |
| 패스 | 패스 | 다음 라인 동료가 받음, 연계 스택 +1 | 인터셉트 |
| 슛 | 슈팅 | GK와 대결 (연계 스택만큼 위력 +) | 블록 |

| 수비 | 스탯 | 특징 |
|---|---|---|
| 태클 | 수비 | 드리블에 강함 |
| 인터셉트 | 수비 | 패스에 강함 |
| 블록 | 수비 + 피지컬 | 슛 위력 감소 |

- 상대 다음 행동은 **의도 아이콘**으로 공개: 확정 / 2지선다 / 비공개. 상대 수준과 "시야" 계열 스킬·유물에 따라 다름.
- 판정 (초안, 프로토타입에서 튜닝):

```
공격력 = 스탯 × 액션 계수 × 스타일 상성 × 컨디션 보정 + 스킬 보너스
성공률 = 공격력 / (공격력 + 수비력)      ※ 최소 10%, 최대 90%
수읽기 성공 (공격에 맞는 수비 선택) 시 수비력 × 1.5
```

### 8.3 스타일 상성 (판정용)

파워 → 테크닉 → 스피드 → 파워 (유리 ×1.25 / 불리 ×0.8). 모든 선수는 스타일 하나를 가진다. 원소·종족과는 별개.

### 8.4 원소와 종족 (경기에서)

- 원소 공명 (4.2절): 편성 화면에서 공명 상태를 미리 표시.
- 종족 패시브 (4.3절): 항상 발동.
- 스킬 이펙트·컷인은 원소 색으로.

### 8.5 텐션 · 연계기 · 경기 체력

- 텐션: 듀얼 성공, 세이브, 이벤트로 상승. 액티브 스킬과 필살기의 비용. 전술 지시의 "텐션 사용"이 AI의 사용 시점을 정한다.
- 연계기: 팀워크 60/80/100에서 해금. 패스 성공 후 발동 (원투 패스, 오버래핑 크로스, 트리플 패스).
- 경기 체력: 선수별. 액션마다 소모, 피지컬이 높을수록 덜 소모. 20% 이하면 전 스탯 −20%.

### 8.6 자동 · 수동 · 길이

- **자동이 기본.** AI는 전술 지시 + 스킬 발동 조건 + 의도 정보로 판단. 배속(2x/4x)과 결과 스킵 제공.
- **수동 개입:** 아무 포제션에서나 "개입" → 그 포제션의 공격/수비 액션과 스킬을 직접 선택. 수동의 기대 이득은 5~10% 이내 **[검증]**. 나중에 빼도 게임이 성립해야 한다.
- 길이: 일반 8포제션 (자동 30~60초, 수동 2~3분), 목표 경기 8/10/12포제션. 런당 3~5경기.
- PvE·PvP 경기는 양쪽 AI. **결정적 시뮬레이션** (시드 고정) → 같은 입력이면 같은 결과, 리플레이 가능.

### 8.7 세로 화면 레이아웃 (초안)

```
┌──────────────────┐
│  상대 GK · 스코어  │  ← 상대 골
│  상대 DF 라인      │
│  상대 MF 라인      │
│  상대 FW 라인      │
│ ───── 중앙 ─────  │
│  우리 FW 라인      │
│  우리 MF 라인      │
│  우리 DF 라인      │
│  우리 GK           │  ← 우리 골
├──────────────────┤
│ 의도 · 텐션 · 체력 │
│ [드리블][패스][슛] │  ← 개입 시만 활성
│ [스킬]  [자동 ▶▶] │
└──────────────────┘
```

공격은 아래에서 위로 올라간다. 공을 가진 선수와 마주보는 수비수를 강조하고 나머지는 어둡게.

## 9. 로그라이크 요소

### 9.1 런 내 랜덤성

훈련 칸 배치 (선수·서포트), 이벤트, 상대 팀 편성·스킬·원소, 루트 선택지, 유물 드롭, 상대 의도 공개 수준.

### 9.2 유물 (라커룸 아이템)

런 동안만 유지. 경계전 승리·루트·이벤트로 획득, 3개 중 1개 선택. 예시:

| 이름 | 효과 |
|---|---|
| 낡은 주장 완장 | 목표 경기에서 팀 컨디션 +1단계 |
| 짝짝이 축구화 | 드리블 성공 시 10% 확률로 경기 체력 +5 |
| 감독의 수첩 | 상대 의도가 한 단계 더 공개됨 |
| 금 간 트로피 | 훈련 효율 +15%, 휴식 효과 −30% |
| 조약의 인장 | 경계전 패배 시 보상 감소 절반 |

### 9.3 리그 등급 (런 난이도)

- 5부 → 4부 → … → 1부 → 조약 리그. 상위 등급 클리어(결승 승리)로 다음 등급 해금.
- 상위일수록 변이 규칙 추가 (부상률 증가, 의도 비공개 확대, 유물 선택지 2개, 상대 원소 공명 보유 등) + 평가 상한과 클럽 포인트 상승.
- 등록 팀에는 "몇 부 리그에서 만들어진 팀인지"가 남는다 (아레나 매칭 기준 중 하나).

## 10. 메타 진행 & 라이브 서비스

### 10.1 가챠

| 풀 | 내용 | 돌파(중복) 효과 |
|---|---|---|
| 선수 | R / SR / SSR 선수 캐릭터 | 스탯 상한 ↑, 초기 스탯 ↑, 고유 스킬 Lv ↑ (SSR), 종족 패시브 강화 |
| 서포트 카드 | R / SR / SSR 카드 | 훈련 보너스 ↑, 초기 유대 ↑, 힌트 확률 ↑, 고유 효과 해금 |

- 확률·천장 **[가정]**: SSR 3% / SR 15% / R 82%, 천장 200회. 픽업 배너 2주 단위.
- 서포트 카드 레벨: 골드로 레벨업, 레벨 상한은 돌파.
- 확률형 아이템 정보 공개 의무 (국내 게임산업법) 준수: 확률 표기, 천장 명시.

### 10.2 플레이로 얻는 성장 (무료 축)

| 항목 | 획득 | 효과 |
|---|---|---|
| 클럽 포인트 | 런 결과 | 클럽 레벨 → 유물 풀, 이벤트 풀, 루트, 전술 슬롯, OB 코치 슬롯, 리그 등급 해금 |
| 선수 친밀도 | 런에 기용한 횟수 | 선수 스토리 해금, 초기 팀워크 +소량 **[가정]** |
| OB 코치 (계승) | 등록 팀의 선수를 지정 (최대 2) | 시즌 시작마다 인자 발동: 같은 포지션 선수에게 스탯 ★, 스킬 힌트 |
| 미션 | 일일·주간 | 무료 재화, 골드 |

가챠는 "누구를·얼마나 강하게"를, 플레이는 "무엇으로·어떤 조건에서"를 넓힌다. 새로운 것을 발견하는 재미는 무료 축에 둔다.

### 10.3 팀 등록

- 런 종료 시 팀 전체 (7명 스탯·스킬 + 전술 지시 + 평가 등급)를 등록 슬롯에 저장. 슬롯 3개 **[가정]**, 클럽 레벨로 확장.
- 등록 팀은 PvE·PvP에서 그대로 쓰인다. 개별 선수는 "선수 명부"에도 남아 OB 코치로 지정 가능.

### 10.4 챌린지 리그 (싱글 엔드게임)

- 1단계 → 50단계 **[가정]**. 단계마다 고정된 AI 팀 (각 종족·국가 클럽). 5단계마다 보스 팀.
- 등록 팀 + 전술 지시로 자동 경기. 재도전 무제한.
- 클리어 보상: 무료 재화, 골드, 클럽 포인트. 첫 클리어 보너스.
- 단계가 올라갈수록 필요한 팀 평가가 오르고, 상대 원소 공명·특정 스킬 대응이 필요해진다 (편성 퍼즐).

### 10.5 아레나 (비동기 PvP)

- 등록 팀 1개를 아레나 팀으로 지정 → 서버에 업로드.
- 상대: 비슷한 랭크의 다른 감독 팀 중 5개 제시, 하나 선택 → 결정적 시뮬로 경기 → 승패로 랭크 포인트.
- 주간 시즌, 랭크 구간별 보상. 리그 등급·팀 평가로 매칭 구간 분리 (돌파 격차 완화).
- 상대 팀은 서버에 저장된 데이터, 경기는 클라이언트에서 시뮬 → 서버는 결과 기록. 부정 방지는 12.2절.

### 10.6 재화 · 행동력

| 재화 | 용도 | 획득 |
|---|---|---|
| 주얼 (무료/유료 구분) | 가챠 | 미션, 런 결과, 챌린지 리그, 결제 |
| 골드 | 서포트 카드 레벨업, 편의 | 런, 아레나, 미션 |
| 클럽 포인트 | 영구 해금 | 런 결과 |

행동력 없음. 런·챌린지·아레나 모두 무제한 (아레나는 일일 승리 보상 횟수만 제한 **[가정]**).

| 필살기 컷인 | 270×120 가로 배너, 8~16프레임 (SSR만) |
| 서포트 카드 일러스트 | 128×176 도트 일러스트 **[가정]** |
| 팔레트 | 캐릭터당 16색 이내. 원소별 포인트 색 (불 빨강 / 물 파랑 / 바람 초록 / 대지 갈색 / 번개 노랑). 종족은 실루엣으로 구분 |

**런치 아트 물량**

| 항목 | 수량 | 단위 작업 |
|---|---|---|
| 선수 20명 (SSR 6 / SR 8 / R 6) | 20 | 스프라이트 6모션 + 초상화 5표정 (+ SSR 컷인 6개) |
| 서포트 카드 20장 | 20 | 일러스트 1장 (선수 캐릭터 재활용 시 신규 디자인 절감) |
| 상대 팀 (챌린지 리그·런 상대) | 종족별 공용 스프라이트 6종 + 팔레트 스왑 | — |
| UI · 필드 · 로비 배경 | — | — |

파이프라인: AI 이미지 생성으로 디자인 초안 → 도트화 후처리 (축소·팔레트 정리·배경 제거) → 손으로 다듬기. 스프라이트 애니메이션은 결국 손 작업.

주요 화면: 클럽 로비 / 편성 / 육성 메인 (훈련 칸) / 이벤트 대화 / 경기 / 루트 선택 / 결과·팀 등록 / 챌린지 리그 / 아레나 / 가챠.

## 12. 기술

### 12.1 클라이언트

- Unity 2D (URP 2D, Pixel Perfect Camera), 세로 고정.
- 모든 밸런스 데이터(스탯, 공식 계수, 이벤트, 스킬, 유물, 상대 팀)는 JSON/CSV → 웹 프로토타입과 공유, 서버 배포로 핫픽스 가능.
- 경기 시뮬은 순수 로직 모듈 (시드 RNG, 정수 연산)로 분리. UI와 무관하게 돌아가야 PvP·리플레이·밸런스 테스트가 된다.

### 12.2 서버 (1인 · 서버 경험 없음 → BaaS)

직접 서버를 짜지 않는다. Unity Gaming Services / PlayFab / Firebase 중 하나 **(검토 필요, 유니티 단계 전에 결정)**.

| 서버에 둬야 하는 것 | 이유 |
|---|---|
| 계정, 인벤토리, 재화 | 데이터 보호 |
| 가챠 뽑기 결과 | 클라이언트 조작 방지. 서버 함수(Cloud Code류)로 뽑기 |
| 결제 영수증 검증 | 필수 |
| 등록 팀 저장·조회, 아레나 매칭·랭킹 | PvP 데이터 |

| 클라이언트에 둬도 되는 것 | 비고 |
|---|---|
| 런 진행 전체, 훈련, 이벤트 | 결과(등록 팀)만 서버에 |
| 경기 시뮬 (런·PvE·PvP) | 결정적 시드. PvP는 결과와 시드를 서버에 보고, 추후 서버 재검증 추가 가능 |

리스크: 런 결과를 클라이언트가 만들기 때문에 등록 팀 조작 가능. 완화 — 평가 등급·스탯 상한을 서버가 캐릭터 돌파 수로 검증, 이상치 탐지. 완전한 방지는 런치 이후.

### 12.3 웹 프로토타입 (유니티 전 단계)

- HTML/JS, 아트 없음 (사각형·숫자·아이콘). 링크 공유.
- 코드는 버리고 데이터와 공식만 가져간다.
- 범위: 13장.

## 13. 프로토타입 범위 (웹)

- 선수 8명 고정 데이터 (종족·원소·스타일 섞어서), 서포트 카드 8장
- 1런 전체: 24턴 + 경계전 3회 + 루트 선택 2회
- 훈련 칸 배치, 우정 훈련, 체력·부상, 팀 컨디션, 팀워크
- 이벤트 20개, 스킬 15개, 유물 10개, 상대 팀 6개
- 경기: 자동 + 수동 개입, 의도 표시, 전술 지시 3항목
- 시드 고정 재현, 밸런스 데이터 JSON 분리
- 팀 평가 산출 → 등록 (로컬)

검증 질문

1. 훈련 칸 선택이 매 턴 고민되는가? 7명 배치가 한 화면에서 읽히는가?
2. 경기 듀얼이 수읽기 싸움으로 느껴지는가? 자동만 돌려도 괜찮은가?
3. 20분에 끝나는가?
4. 끝나고 "한 판 더" 하고 싶은가? 팀 평가를 올리고 싶은 동기가 생기는가?

## 14. 리스크

- **1인 라이브 서비스**: 배너·이벤트 운영, CS, 서버 비용이 개발보다 큰 짐이 된다. 런치 스코프를 극단적으로 줄이고 (챌린지 리그 + 아레나 + 배너 1종), 자동화 가능한 운영만 남긴다.
- **7명 동시 육성의 인지 부하**: 훈련 칸 UI가 답이다. 프로토타입에서 못 읽히면 스탯을 3종으로 줄이거나 자율 훈련 비중을 높인다.
- **패배해도 계속 → 긴장감 하락**: 평가 상한·보상 차이가 충분히 커야 목표 경기가 무겁다. 수치 검증.
- **돌파 격차가 PvP 지배**: 매칭 구간 분리 + 편성 퍼즐(원소 공명·상성)로 순수 스탯 싸움을 피한다.
- **아트 물량**: 캐릭터 20명 × (스프라이트 6 + 초상 5) + 컷인 6은 1인에게 큼. 종족 공용 베이스 + 팔레트 스왑으로 상대 팀을 해결하고, 선수 캐릭터를 서포트 카드로 재활용한다.
- **IP**: 레퍼런스는 시스템만. 캐릭터·이름·아트·UI 레이아웃은 독자적으로.
- **법규**: 확률 공개, 미성년자 결제 한도, 청약 철회 안내.

## 15. 결정 필요 사항 (다음 라운드)

1. **캐스트 구성과 타겟**: 전원 여성 캐릭터 (우마·사커스피리츠식) / 혼성. 타겟 연령·성별. 아트와 대사 톤이 여기서 갈린다.
2. **세계 이름, 종족 목록 확정, 감독의 스토리 훅** (왜 신생 클럽을 맡았나).
3. **서포트 카드의 정체**: 선수 캐릭터 재활용 + NPC 코치 (7.5절 가정)로 갈 것인가, 완전히 별도 캐릭터군인가.
4. **OB 코치(계승) 유지 여부**: 팀 육성이라 계승이 v0.1보다 약해졌다. 빼고 클럽 레벨로 통합해도 된다.
5. **스탯 5종 유지 vs 3종 축소** (공격·수비·피지컬): 7명 동시 육성이면 3종이 읽기 쉬울 수 있다. 프로토타입에서 5종으로 먼저 시험 후 결정해도 됨.
6. **컨디션 팀 단위 vs 선수 단위**.
7. **BaaS 선택**: Unity Gaming Services / PlayFab / Firebase. 유니티 착수 전까지.
8. **런치 스코프**: 챌린지 리그 단계 수, 아레나 시즌 길이, 배너 주기.
