## 2. 레퍼런스에서 가져올 것 / 버릴 것

### 2.1 우마무스메 → 육성 뼈대

| 원작 요소 | 우리 게임에서 |
|---|---|
| 턴제 훈련 (5종 중 택1) | 슈팅 / 드리블 / 패스 / 수비 / 피지컬 훈련 |
| 서포트 카드 6장 편성, 훈련 칸에 랜덤 등장 | 서포트 카드 = **경기에 함께 뛰는 동료** |
| 우정 훈련 | 콤비 훈련 + 경기 중 연계기 해금 |
| 체력 / 의욕 / 실패율 | 체력 / 컨디션 / 부상률 |
| 목표 레이스 미달 시 육성 종료 | 목표 경기 패배 시 런 종료 |
| 랜덤 이벤트 + 선택지 | 동일 + 로그라이크식 리스크/보상 이벤트 |
| 인자 계승 | 은퇴한 선수 = 레전드 → 다음 런의 계승원 |

버리는 것: 가챠 중심 성장, 1시간 넘는 육성 1회, 지켜보기만 하는 자동 레이스

### 2.2 사커스피리츠 → 경기 전투

| 원작 요소 | 우리 게임에서 |
|---|---|
| 포지션 라인을 돌파해 나가는 턴제 경기 | 7인제, 라인 돌파 듀얼 |
| 공격 선택 vs 수비 선택의 1:1 대결 | 드리블/패스/슛 vs 태클/인터셉트/블록 |
| 캐릭터별 액티브 스킬, 화려한 컷인 | 도트 컷인 필살기 |
| 속성 상성 | 3스타일 상성 (파워/스피드/테크닉) |
| 팀 편성 시너지 | 유대 기반 연계기 |

버리는 것: 복잡한 장비 강화 체계, 행동력 과금 구조

### 2.3 로그라이크 → 판 구조

- 런마다 달라지는 훈련 배치, 이벤트, 상대 팀, 유물
- 실패하면 처음부터. 대신 레전드 등록과 해금으로 영구 성장
- 상대의 **의도 표시**(다음 행동 예고)로 턴제 경기에 수읽기 재미 부여
- 난이도 단계 (리그 승격)

## 3. 디자인 기둥

1. **한 턴의 선택이 쌓인다** — 무엇을 훈련할지, 언제 쉴지, 누구와 친해질지가 그대로 경기력이 된다.
2. **경기는 수읽기 싸움** — 상대 의도를 보고 액션과 스킬을 고르는 턴제 듀얼. 스탯만으로는 이길 수 없다.
3. **매 런은 다르고, 레전드는 남는다** — 랜덤성으로 반복 플레이, 계승으로 장기 목표.
4. **도트로 살린 캐릭터성** — 작은 스프라이트, 표정 풍부한 초상화, 필살기 도트 컷인.

## 4. 코어 루프

```
[메타 루프]  클럽하우스(로비): 주인공 · 서포트 덱 6장 · 계승 레전드 2명 선택
                 │
[런 루프]     1년차 ─► 2년차 ─► 3년차 ─► (EX 대회)
                 │   시즌마다: 훈련 턴 × 16 + 일반 경기 + 목표 경기
                 │   목표 경기 패배 → 런 종료
                 ▼
             은퇴 평가 (G ~ S 등급) → 레전드 등록 + 해금 포인트
                 │
                 └──► 다음 런의 계승원 / 드림팀 편성

[턴 루프]    상태 확인(체력·컨디션·서포트 위치) → 행동 선택 → 결과·이벤트 → 스킬 습득
```

## 5. 런 구조

| 구간 | 턴 수 | 목표 경기 | 비고 |
|---|---|---|---|
| 1년차 (유스 데뷔) | 16턴 | 지역 리그 4강 | 튜토리얼 성격, 유대 쌓기 |
| 2년차 (전국 도전) | 16턴 | 전국대회 본선 진출 | 여름 합숙 (특수 훈련 4턴) |
| 3년차 (정점) | 16턴 | 전국대회 우승 | 난이도 급상승, 보스 팀 등장 |
| EX (해외 유스컵) | 3경기 | 선택 도전 | 클리어 시 평가 보너스 |

**시즌 사이 루트 선택** (3갈래 중 1):

| 루트 | 효과 |
|---|---|
| 명문 캠프 | 다음 시즌 훈련 효율 +20%, 부상률 +5%p |
| 해외 원정 | 고난도 친선전 2회, 승리 시 희귀 유물 |
| 회복 리조트 | 체력·컨디션 완전 회복, 확정 이벤트 1회 |

총 48턴 + 경기 약 10회 기준 40분 목표 (튜닝 대상).

## 6. 육성 시스템

### 6.1 스탯

| 스탯 | 경기에서 쓰이는 곳 |
|---|---|
| 슈팅 | 슛 위력, 중거리 슛 |
| 드리블 | 드리블 돌파 |
| 패스 | 패스 성공, 연계기 위력 |
| 수비 | 태클 · 인터셉트 · 블록, GK 세이브 |
| 피지컬 | 경기 중 체력 소모 감소, 몸싸움 보정 |

스탯 상한 1200 **[가정]**, 등급 표기 G ~ S.

### 6.2 한 턴의 행동

| 행동 | 효과 |
|---|---|
| 훈련 (5종) | 해당 스탯 상승 (+부가 스탯), 체력 소모, 실패 시 부상 |
| 휴식 | 체력 회복 |
| 외출 | 컨디션 상승, 서포트 이벤트 발생 |
| 코치 상담 | 스킬 힌트 획득 또는 스킬 구매 |
| 친선전 | 스킬 포인트·유물 획득 기회, 체력 소모 큼 |

### 6.3 체력 / 컨디션 / 부상

- 체력 0~100. 50 미만부터 훈련 실패율 상승 → 실패 시 부상 (스탯 하락, 일정 턴 결장)
- 컨디션 5단계 (최악 ~ 최고): 훈련 효율 −20% ~ +20%, 경기 스탯 보정

### 6.4 서포트 카드 = 동료 ★ 핵심 차별점

- 런 시작 시 6장 편성. 포지션 제약: GK 1장 필수 (주인공이 GK면 면제) **[가정]**
- 매 턴 서포트들이 훈련 5종 칸에 랜덤 배치 → 같은 칸에 여럿 몰리면 효율 상승
- 유대 게이지 0~100. 함께 훈련하거나 이벤트로 상승
  - 80 이상: **콤비 훈련** (효율 대폭 상승), **경기 연계기 해금**
- 경기에서는 서포트 카드 캐릭터가 실제로 필드에 선다. 카드 레벨과 유대가 곧 동료의 경기력

→ 육성 중 누구와 친해졌는지가 그대로 경기의 팀 전력이 된다. 우마의 "서포트 카드"와 사커스피리츠의 "팀 편성"을 하나로 합치는 연결 고리.

### 6.5 이벤트

- 종류: 주인공 스토리(연속), 서포트 이벤트, 랜덤 이벤트, 시즌 이벤트
- 로그라이크 성격 강화용 **리스크 이벤트** 예시
  - "비밀 특훈": 드리블 +40, 50% 확률로 부상
  - "스카우트의 제안": 희귀 유물을 얻는 대신 서포트 1명 이탈

### 6.6 스킬

| 종류 | 방식 | 예시 |
|---|---|---|
| 액티브 | 경기 중 직접 선택, 텐션 게이지 소모 (사커스피리츠식) | "라인 브레이커": 드리블 성공 시 한 라인 추가 전진 |
| 패시브 | 조건 충족 시 자동 발동 (우마식) | "막판 집중": 후반 마지막 2포제션 슈팅 +15% |
| 고유 필살기 | 주인공당 1개, 도트 컷인 연출. 3년차에 각성 | — |

습득: 이벤트로 힌트 획득 → 스킬 포인트로 구매 (힌트 레벨만큼 할인)

## 7. 경기 시스템

### 7.1 기본 규칙

- **7인제**: GK 1 · DF 2 · MF 2 · FW 2 (주인공 1 + 서포트 6 = 7명). 포메이션 변경 가능
- 경기 = **12포제션**. 수비 성공 시 공을 뺏은 팀이 그 라인에서 바로 역습 시작
- 공격 경로: 우리 빌드업 → 상대 FW 압박 돌파 → 상대 MF 돌파 → 상대 DF 돌파 → 슛 vs GK
- 한 라인 돌파 = 공 가진 선수 vs 그 라인 수비수 1명의 듀얼

### 7.2 듀얼

| 공격 | 사용 스탯 | 성공 시 | 약한 상대 수비 |
|---|---|---|---|
| 드리블 | 드리블 | 같은 선수가 다음 라인으로 전진 (체력 소모 큼) | 태클 |
| 패스 | 패스 | 다음 라인 동료가 받음, **연계 스택 +1** | 인터셉트 |
| 슛 | 슈팅 | GK와 대결 (연계 스택만큼 위력 보너스) | 블록 |

| 수비 | 사용 스탯 | 특징 |
|---|---|---|
| 태클 | 수비 | 드리블 상대로 강함 |
| 인터셉트 | 수비 | 패스 상대로 강함 |
| 블록 | 수비 + 피지컬 | 슛 위력 감소 |

- 상대의 다음 행동은 **의도 아이콘**으로 공개: 확정 / 2지선다 / 비공개 (상대 수준, '시야' 계열 스킬·유물에 따라 달라짐)
- 판정 공식 (초안):

```
공격력 = 스탯 × 액션 계수 × 상성 보정 × 컨디션 보정 + 스킬 보너스
성공률 = 공격력 / (공격력 + 수비력)      ※ 최소 10%, 최대 90%
수읽기 성공 (공격에 맞는 수비 선택) 시 수비력 × 1.5
```

### 7.3 스타일 상성

파워 → 테크닉 → 스피드 → 파워 (유리 ×1.25 / 불리 ×0.8). 모든 캐릭터는 스타일 하나를 가진다.

### 7.4 텐션 게이지 & 연계기

- 듀얼 성공, 세이브, 관중 이벤트로 팀 텐션 상승 → 액티브 스킬과 필살기의 비용
- 유대 80 이상인 동료에게 패스 성공 시 연계기 사용 가능 (예: "원투 패스", "오버래핑 크로스")

### 7.5 경기 체력

- 선수마다 경기 체력. 액션마다 소모, 피지컬이 높을수록 덜 소모. 20% 이하면 전 스탯 −20%
- 교체 없음 **[가정]** → 7명 전원 풀타임이라 피지컬 스탯의 가치가 생김

### 7.6 조작 방식 **[가정]**

- 공격: 공 가진 선수의 액션을 직접 선택 (주인공은 스킬 선택지 多, 동료는 액티브 1개)
- 수비: 상대 의도를 보고 수비 액션 선택
- 한 경기 4~6분 목표. "빨리감기 (AI 위임)" 옵션 제공

## 8. 로그라이크 요소

### 8.1 런 내 랜덤성

서포트 카드 훈련 배치, 이벤트, 상대 팀 편성과 스킬, 루트 선택지, 유물 드롭

### 8.2 유물 (가칭: 라커룸 아이템)

런 동안만 유지되는 패시브 효과. 예시:

| 이름 | 효과 |
|---|---|
| 낡은 주장 완장 | 목표 경기에서 팀 전원 컨디션 +1단계 |
| 짝짝이 축구화 | 드리블 성공 시 10% 확률로 체력 +5 |
| 감독의 수첩 | 상대 의도가 한 단계 더 공개됨 |
| 금 간 트로피 | 훈련 효율 +15%, 휴식 효과 −30% |

### 8.3 실패와 구제

- 목표 경기 패배 = 런 종료. 단, 런마다 **재경기권** 1장 **[가정]**
- 도중에 끝나도 그 시점의 선수는 레전드로 등록 (평가 등급은 낮게)

### 8.4 난이도 단계 (승격)

5부 리그 → … → 1부 리그 → 챔피언스. 단계마다 변이 규칙 추가 (부상률 증가, 상대 의도 비공개 확대, 재경기권 제거 등)

## 9. 메타 진행

- **레전드 등록**: 런이 끝난 선수의 스탯·스킬·평가 등급 저장
- **계승**: 런 시작 시 레전드 2명 선택 → 인자 (스탯 ★1~3, 스킬 인자, 고유 인자)가 시즌 시작마다 확률 발동
- **해금**: 런 보상 포인트로 새 주인공, 서포트 카드, 유물 풀, 이벤트 해금. 서포트 카드 레벨업
- **드림팀**: 레전드 7명으로 팀 편성 → 엔드게임 도전 모드 (보스 러시, 주간 시드 대회). 비동기 PvP는 후순위

## 11. MVP (버티컬 슬라이스) 범위

- 주인공 3명 (FW · MF · DF 각 1)
- 서포트 카드 12장 (GK 2장 포함)
- 1년차 한 시즌만 (16턴 + 목표 경기)
- 이벤트 30개, 스킬 25개, 유물 15개, 상대 팀 6개
- 레전드 등록 → 계승까지 1사이클

MVP로 검증할 질문
1. 훈련 선택이 매 턴 고민되는가?
2. 경기 듀얼이 수읽기 싸움으로 느껴지는가?
3. 끝나고 "한 판 더" 하고 싶은가?

## 12. 리스크 & 메모

- 레퍼런스는 **시스템만** 참고한다. 캐릭터, 이름, 아트, UI 레이아웃은 독자적으로 (IP 이슈 회피)
- 육성(느긋함)과 경기(긴장감)의 템포 차이 → 경기 빈도와 길이 튜닝이 관건
- 서포트 카드 = 필드 캐릭터 구조라서 카드 수 = 도트 작업량. 캐릭터 1명당 스프라이트 + 초상화 + 컷인 비용 산정 필요

## 13. 결정 필요 사항

1. **BM**: 패키지 판매 vs 가챠 라이브 서비스
2. **육성 대상**: 주인공 1명 vs 팀 전체
3. **경기 조작**: 풀 수동 턴제 vs 자동 진행 + 결정적 순간만 개입
4. **세계관**: 현대 학원 축구 / 판타지 (정령·마법 축구) / SF
5. **플랫폼 & 엔진**: PC(Steam) / 모바일, Godot / Unity
