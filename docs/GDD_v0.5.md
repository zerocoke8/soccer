방향은 사용자 결정이고, **수치(×1.0 / ×0.8 / ×1.15 / ×0.85 / 증폭 배율 등)는 모두 [가정]** — 9.8~9.11절 참조, 시뮬로 맞춘다.

계기: 프로토타입 v0.2 플레이 피드백 — "태클·인터셉트·블록은 뭘 골라도 그냥 다 방어 액션 아냐? 상대의 선택과 나의 선택이 의미가 있어?" 측정 결과 수비 3종은 짝 맞히기(×1.5) 외에 차이가 없었다. 시즌 1·2는 공개 +1 효과(정찰·수첩)가 겹쳐 답이 보였고, 시즌 3은 찍기였다. 연계(패스 +10%)도 골 성공률에 영향이 없었다. 초안은 검토 에이전트 3명(결정 일관성 / 수치·지배 전략 / 구현·모바일 화면)의 검토를 거쳐 수치와 규칙을 보강했다. 상세는 9.8~9.11절.

## 3. 디자인 기둥

1. **한 턴에 팀 전체를 굴린다** — 어느 칸을 고르느냐가 "누구를 키우고, 누구와 친해지고, 누구를 쉬게 하느냐"를 동시에 정한다. 7명이지만 결정은 한 번.
2. **경기는 확률을 읽는 싸움, 자동으로도 충분하다** — 스탯으로 정해지는 상대 성향을 보고 위험을 관리한다. 확정 정보는 간파 스킬로만. AI는 성향대로 뛰고, 원하면 결정적 포제션에만 개입한다. 수동이 유리한 폭은 작게.
3. **매 런은 다르고, 팀은 남는다** — 런 결과물이 곧 PvE·PvP 팀. 20분 한 판이 엔드게임으로 이어진다.
4. **도트로 살린 종족과 원소** — 작은 스프라이트, 표정 풍부한 초상화, 종족·원소가 한눈에 읽히는 색과 실루엣.

## 4. 세계관

### 4.1 설정

- 대륙 이름 **미정**. 대전쟁 끝에 모든 종족이 **전쟁 금지 조약**을 맺었다.
- 국경과 자원 분쟁은 전쟁 대신 공식 경기 **경계전(境界戰)** 으로 결정한다. 이기면 영토와 명예, 지면 양보.
- 각 나라·종족은 대표 클럽을 두고, 조약 리그가 경계전 일정을 관리한다.
- 플레이어는 **신생 클럽의 감독**. 왜 신생 클럽을 맡게 됐는지(스토리 훅)는 미정.
- 런의 세 시즌 = 지방 조약 리그 → 종족 연맹컵 → 대륙 경계전. 각 시즌 끝의 목표 경기가 경계전.

### 4.2 원소 (5종) **[가정]**

| 원소 | 이미지 | 팀 공명 보너스 (같은 원소 3명 이상 편성 시) |
|---|---|---|
| 불 | 공격적, 폭발력 | 슛 위력 +5% |
| 물 | 유연, 지구력 | 경기 체력 소모 −10% |
| 바람 | 연계, 속도 | 패스 성공률 +5% |
| 대지 | 견고, 수비 | 수비 판정 +5% |
| 번개 | 순간, 텐션 | 텐션 획득 +20% |

- 4명 이상이면 보너스 1.5배. 원소는 **상성 판정에 쓰지 않는다**.
- 스킬 이펙트·컷인 색·캐릭터 성격에 반영. 편성 목표(공명)를 주어 가챠 캐릭터 수집에 이유를 만든다.

### 4.3 종족 **[가정]**

| 종족 | 스탯 성향 | 종족 패시브 예시 |
|---|---|---|
| 인간 | 균형, 성장률 높음 | 훈련 효율 +5% |
| 엘프 | 패스·테크닉 | 패스 실패 시 50% 확률로 공 유지 |
| 드워프 | 수비·피지컬 | 버티기 수비력 +10% |
| 수인 (늑대·고양이·토끼 등 계열) | 스피드·드리블 | 드리블 성공 시 체력 소모 −20% |
| 정령족 (원소의 화신) | 원소 스킬 강화, 체력 낮음 | 원소 공명 보너스 +50% (본인 원소만) |
| 거인족 | 파워·헤더, 스피드 낮음 | 몸싸움(태클·헤더) 판정 +15% |

- 종족 수는 런치 캐릭터 20명에 맞춰 조정. 6종 × 3~4명.
- 종족 = 실루엣과 색의 차이. 도트에서 한눈에 구분되어야 한다.

### 4.4 감독 (플레이어)

- 이름 설정 가능. 초상화 없음 **[가정]**. 이벤트는 감독 ↔ 선수·서포트 대화.
- 감독의 역할: 편성, 훈련 칸 선택, 호출, 전술 지시, 스킬 부여, 경기 개입.

## 7. 육성 시스템

### 7.1 캐릭터 데이터 구조 (가챠 시점에 갖고 있는 것)

| 항목 | 내용 |
|---|---|
| 기본 정보 | 종족, 원소, 스타일(파워/스피드/테크닉), 레어도 |
| 초기 스탯 5종 | 레어도·돌파로 결정. 합 가이드 R 900~1000 / SR 1100~1250 / SSR 1350~1500 |
| **성장률** | 스탯별 훈련 효율 보정 0.8~1.3. 같은 칸을 골라도 누가 있느냐에 따라 상승치가 다름 |
| **포지션 적성** | GK / DF / MF / FW 각각 A · B · C · — (7.2절) |
| 고유 스킬 1개 | SSR = 필살기(액티브, 컷인) / SR = 액티브(컷인 없음) / R = 패시브. GK는 패시브 허용 |
| **연계 특성 1개** (v0.5) | 킬패스·피니셔·크로서·타깃맨·침투·볼 운반·철벽·빠른 배급 등 (9.10절). 돌파 3단계에서 효과 강화 **[가정]** |
| 종족 패시브 | 4.3절 |
| 스킬 슬롯 3칸 **[가정]** | 런 중 배우는 스킬용. 런마다 비워서 시작 |
| 돌파 0~4 | 스탯 상한·초기 스탯 ↑, 고유 스킬 Lv ↑, 2·4단계에서 부 포지션 적성 +1, 3단계에서 연계 특성 강화 **[가정]** |

런 중 얻는 것(스탯 성장, 슬롯 스킬, 팀워크, 전술)은 **등록 팀**에 남고, 다음 런은 다시 위 상태에서 시작한다.

### 7.2 포지션 적성

| 등급 | 의미 | 경기 판정 스탯 | 비고 |
|---|---|---|---|
| A | 주 포지션 | ×1.0 | 캐릭터당 정확히 1개 |
| B | 부 포지션 | ×0.9 | 대부분 1개 보유 |
| C | 억지로 가능 | ×0.75 | 편성 화면에 경고 |
| — | 불가 | 배치 불가 | |

- **GK는 A 또는 B만 허용.** C 골키퍼는 경기를 무너뜨려 시행착오 비용이 너무 크다.
- 훈련에도 영향: 선수는 **배치된 포지션** 기준으로 훈련 칸에 끌린다 (FW로 세운 MF는 슈팅·드리블 칸에 더 자주).
- 적성 올리기: 돌파 2·4단계에서 B→A, C→B **[가정]**. OB 코치 인자 "적성 ★"로 런 동안 한 등급 상승.

예시:

| 캐릭터 | GK | DF | MF | FW |
|---|---|---|---|---|
| 늑대 수인 윙어 | — | C | B | A |
| 엘프 플레이메이커 | — | — | A | B |
| 드워프 센터백 | — | A | C | — |
| 정령족 골키퍼 | A | C | — | — |

런치 20명은 주 포지션을 GK 3 / DF 5 / MF 6 / FW 6으로 배분하고 전원에게 B 부 포지션을 하나씩 준다. "이 셋 중 누굴 MF로 내리지" 같은 편성 퍼즐이 생겨야 한다.

### 7.3 스탯

| 스탯 | 경기에서 쓰이는 곳 | 주 스탯인 포지션 |
|---|---|---|
| 슈팅 | 슛 위력 | FW |
| 드리블 | 드리블 돌파, 크로스(패스+드리블)/2 | FW, MF |
| 패스 | 패스 성공, 크로스(패스+드리블)/2, 인터셉트(수비+패스)/2 | MF |
| 수비 | 태클·인터셉트·버티기 전부, GK 세이브 | DF, GK |
| 피지컬 | 경기 체력 소모 감소, 태클(수비+피지컬)/2, 헤더(슈팅+피지컬)/2 | DF, GK |

- 범위 0~1000 **[가정]**, 등급 G~S. 화면에는 포지션 주 스탯 2개를 크게.
- 훈련 시 주 스탯 大 + 부 스탯 小 (슈팅→드리블, 드리블→패스, 패스→슈팅, 수비→피지컬, 피지컬→수비).

### 7.4 훈련 턴 — 팀 동시 육성의 핵심 ★

**흐름**

```
① 칸 확인 (배치 · 예상치 · 위험)  →  ② 칸 탭 → 상세  →  ③ 실행 (또는 다른 행동)
→  ④ 결과 연출  →  ⑤ 이벤트 (있으면, 선택지 2개)  →  다음 턴
```
목표 한 턴 10~20초. 판단에 필요한 정보는 ①에서 전부 보이고 ②는 확인용.

**배치 규칙**
- 매 턴 훈련 칸 5개(슈팅·드리블·패스·수비·피지컬)에 **선수 7명(부상자 제외)과 서포트 6장이 랜덤 배치**. 선수 배치는 배치된 포지션의 성향 가중, 서포트는 자기 타입 칸 확률 높음.
- 감독은 칸 **하나**를 고른다.
  - 그 칸 선수 전원: 주 스탯 大 + 부 스탯 小, 체력 −20. 체력 낮은 선수는 개별 실패·부상 판정.
  - 그 칸 서포트: 훈련 효율 보너스, 유대 +7, 힌트 확률. 유대 80 이상 + 카드 타입 = 칸 타입이면 **우정 훈련**.
  - 다른 칸 선수: 자율 훈련 (효율 20%, 체력 소모 없음) **[가정]**.
  - 같은 칸에 여럿이면 함께 훈련 보너스(+5%/명) + 팀워크 상승.

**① 훈련 메인 화면 (세로)**

```
┌──────────────────────────────┐
│ 시즌1 · 3/8턴     컨디션 ●●●○○  │
│ 팀워크 42   다음 경계전: 5턴 후 (상대: 대지·파워·드리블 성향) │
├──────────────────────────────┤
│ 체력  FW▮▮▮▮ FW▮▮▯▯ MF▮▮▮▯ MF▮▮▮▮ DF▮▯▯▯ DF▮▮▮▯ GK▮▮▮▮ │
├──────────────────────────────┤
│ 슈팅    👤👤    🃏★    +38 / +12   실패 8%  추천 │
│ 드리블  👤      🃏🃏💡  +25 / +8    실패 2%       │
│ 패스    👤👤👤          +30 / +10   실패 15%      │
│ 수비    👤      🃏      +22 / +7    실패 3%       │
│ 피지컬  —       🃏      자율 훈련만               │
├──────────────────────────────┤
│  [휴식]  [외출]  [전술 미팅]  [친선전]  [호출 1]  │
└──────────────────────────────┘
```
- 👤 선수 얼굴 (포지션 색 테두리, 체력 낮으면 어둡게) · 🃏 서포트 (★ 우정 훈련 가능, 💡 이번 턴 힌트 가능)
- 예상 상승치 = 주/부 스탯 합계(서포트 보너스 반영) · 실패율 = 그 칸에서 가장 위험한 선수 기준
- 상단에 **다음 경계전 상대의 원소·스타일·주 성향**(예: 드리블 위주)을 미리 띄움 → 훈련 방향이 생김 (태클 수비수를 키울지, 인터셉트 수비수를 키울지)

**② 칸 탭 → 상세 시트**

```
┌ 슈팅 훈련 ─────────────────────────┐
│ 선수A (FW)   슈팅 +38  드리블 +12   체력 −20  실패 8%  │
│ 선수B (FW)   슈팅 +34  피지컬 +10   체력 −20  실패 3%  │
│ 서포트 · 코치C   유대 84 → 우정 훈련 ×1.6, 유대 +7     │
│ 자율 훈련 (나머지 5명)   해당 칸 스탯 +5               │
│                                         [훈련하기]  │
└──────────────────────────────────────┘
```

**매 턴 고민이 생기는 다섯 축**

| 축 | 고민 |
|---|---|
| 상승치 | 선수 3명 몰린 패스 칸이 총량은 최고 |
| 우정 훈련 | 슈팅 칸은 2명이지만 ★ 서포트가 있어 효율 1.6배 |
| 체력 · 부상 | 패스 칸에 체력 25%인 DF. 다치면 경계전 결장 |
| 편중 | GK가 3턴 연속 자율 훈련만 |
| 다음 경계전 | 5턴 뒤 파워 팀. 수비 라인이 약하면 진다 |

**감독의 개입 수단**
- **호출권**: 시즌당 1장 **[가정]**. 선수 한 명을 원하는 칸으로 부른다 (턴 소모 없음). 유물·클럽 레벨로 증가.
- **추천 칸**: 감독 AI가 한 칸에 "추천" 표시. 생각 안 하고 싶은 턴엔 그걸 누른다. 훈련 전체 자동 진행은 런치에 넣지 않는다 — 훈련 선택이 이 게임의 육성 재미 그 자체.

**[검증]** 7명 배치가 한 화면에서 읽히는가. 다섯 축이 실제로 부딪히는 턴이 24턴 중 절반 이상인가.

### 7.5 턴 행동

| 행동 | 효과 (초안 수치) |
|---|---|
| 훈련 (5칸 중 1) | 7.4절 |
| 휴식 | 전원 체력 +40, 30% 확률로 컨디션 +1 |
| 외출 | 친구 타입 서포트가 있으면 그 카드와 외출: 유대 +10, 컨디션 +1, 카드 이벤트. 없으면 컨디션 +1, 전원 체력 +10 |
| 전술 미팅 | 팀워크 +10, 전술 지시·포메이션·포지션 변경, 스킬 구매 |
| 친선전 | 6포제션 경기. 스킬 포인트 +20/+10, 승리 시 30% 유물. 전원 체력 −30 |
| 호출 | 턴 소모 없음. 호출권 1장 소모 |

훈련만 24턴 하는 게 최적이 아니게 수치를 잡는다. 휴식 3~4턴, 미팅 2~3턴이 자연스럽게 섞이도록. **[검증]**

### 7.6 체력 · 컨디션 · 부상 · 팀워크

- **체력** 선수별 0~100. 실패율: 60 이상 2% / 40~59 10% / 20~39 25% / 20 미만 45%. 실패 시 스탯 −5, 50%로 부상(2턴 결장 → 그 자리는 유스 선수가 대체).
- **컨디션** 팀 단위 5단계 **[가정]**. 훈련 효율 ×0.8~1.2, 경기 스탯 ×0.9~1.1.
- **팀워크** 0~100. 같은 칸 다인 훈련(+2/명), 전술 미팅(+10), 이벤트. 패스 성공률 보정(+10%/100)과 **연계 특성 증폭**(60 / 80 / 100에서 ×1.25 / ×1.5 / ×2, 9.10절).

### 7.7 서포트 카드 (우마무스메 방식 재확인)

우마무스메에서 서포트 카드가 하는 일: 훈련 칸에 랜덤 등장(자기 타입 칸에 잘 나옴) → 같이 훈련하면 효율 보너스·유대·힌트 → 유대 80에서 우정 훈련 → 카드 고유 이벤트 → 친구 타입은 외출 담당 → 초기 스탯·레이스 보너스 등 부가 효과 → **레이스에는 출전하지 않음**. 우리도 그대로.

- 편성 6장 = 내 카드 5장 + **렌탈 1장**(친구/팔로우 카드).
- 타입: 슈팅 / 드리블 / 패스 / 수비 / 피지컬 / **친구**. 친구 타입은 훈련 보너스 없음, 외출 담당.
- 효과: 훈련 효율, 우정 보너스, 초기 유대, 힌트 확률·레벨, 실패율 감소, 초기 스탯 보너스, 경기 보너스(경기 후 스탯 추가), 고유 효과.
- 성장: 골드로 레벨업, 중복으로 **돌파 0~4** → 레벨 상한·효과 강화·고유 효과 해금.
- 카드의 정체(세계관): 선수 캐릭터의 다른 일러스트 + 코치·감독·전설의 OB 등 NPC **[가정]**. 선수를 카드로도 쓰면 디자인 수를 늘리지 않고 카드 풀을 채운다.

### 7.8 이벤트

- 종류: 선수 이벤트(캐릭터 전용), 서포트 이벤트(유대 60에서 1회), 랜덤, 시즌 시작, 경계전 직전, 루트.
- 감독 시점 대화 2~4줄. **선택지는 항상 2개**, 감독의 결정으로 표현.
- **결과 공개** **[가정]**: 안전한 쪽은 확정 수치, 위험한 쪽은 확률과 범위. 20분 게임에서 결과를 숨겨 외우게 하면 피로만 쌓인다. 재미는 "언제 뜨느냐"의 랜덤에서 나온다.

```
"선수B가 야간 특훈을 하고 싶다고 합니다."
  ▸ 허락한다      슈팅 +30 / 50%: 체력 −40, 부상
  ▸ 쉬라고 한다   컨디션 +1
```

### 7.9 스킬

| 종류 | 방식 | 예시 |
|---|---|---|
| 고유 (가챠 시점) | SSR 필살기(컷인) / SR 액티브 / R 패시브. 돌파로 Lv | "라인 브레이커": 드리블 성공 시 한 라인 추가 전진 |
| 학습 액티브 | 텐션 소모. **AI 발동 조건 내장** (수동 개입 시 직접 선택도 가능) | "간파": 이번 듀얼 상대 선택 확정 공개 — 유일한 확정 정보 (9.11절) |
| 학습 패시브 | 조건 충족 시 자동 | "막판 집중": 마지막 2포제션 슈팅 +15% |

- 습득: 힌트(서포트 이벤트·우정 훈련) → 팀 스킬 포인트로 구매(힌트 레벨당 −10%) → 선수 지정 → 슬롯 3칸.
- 포지션 조건 스킬은 **현재 배치 포지션** 기준. B 포지션에 세우면 고유 스킬은 살아 있고 스탯 페널티만.
- 모든 액티브 스킬은 "언제 쓸지"가 정의되어 있어야 한다. 수동을 나중에 빼도 스킬 시스템이 남는다.

### 7.10 전술 지시 ★ (런과 PvP를 잇는 장치)

편성 화면에서 초기값, 전술 미팅에서 변경. 등록 팀에 함께 저장되어 PvE·PvP 자동 경기에서 쓰인다.

| 항목 | 선택지 |
|---|---|
| 공격 성향 | 드리블 위주 / 균형 / 패스 위주 |
| 슛 타이밍 | 라인 다 뚫고 / 기회 보이면 중거리 |
| 수비 성향 | 태클 선호 / 균형 / 인터셉트 선호 / 버티기 선호 |
| 텐션 사용 | 아끼기 / 즉시 / 결승골 상황만 |
| 듀얼 담당 | 최고 수비수 / 상성 유리한 선수 |

공격·수비 성향 지시는 해당 액션의 성향값(세제곱 전)에 ×1.15 **[가정]** (확률로는 약 +10%p), 슛 타이밍은 중거리 성향에 들어간다 (9.9절). v0.4의 "의도 따라가기"(readIntent)는 폐지 — 기존 데이터·저장 팀은 "균형"으로 변환.

수동 개입 = 이 지시를 **한 포제션만** 덮어쓰기. 전술 프리셋 슬롯은 클럽 레벨로 증가.

## 9. 경기 시스템

> **v0.4 변경 — 화면 위치 = 규칙 위치**
> 프로토타입에서 "선수가 움직이지 않아 공이 어디 있는지 모른다"는 문제가 확인됐다. 예: 상대가 우리 박스에서 슛 직전인데, 화면에는 상대 FW가 하프라인 너머 상대 진영에 서 있었다.
> 원인은 규칙이 아니라 표현이다. 규칙은 이미 위치를 갖고 있다 — 역습이 "공을 뺏긴 그 지점"에서 시작하도록 짜여 있다. 그런데 화면은 편성 위치를 고정으로 그려서 규칙 상태와 어긋났다.
> 그래서 경기장을 **5구역**으로 나누고, 공과 14명 전원을 **항상 규칙상 위치에** 그린다. 매 듀얼마다 선수들이 새 위치로 움직인다. 판정 공식과 수치는 바꾸지 않는다 (밸런스 영향 없음).

**v0.3 화면 vs v0.4 화면** (같은 순간: 상대 FW가 우리 박스에서 GK와 1:1)

```

 상대 GK                          Z5        ○G           상대 골
 상대 DF  DF                      Z4
 상대 MF  MF                      Z3    ○D        ○D     상대 DF: 하프라인까지 올라옴
 상대 FW  ⚽FW  ← 상대 진영에      Z2  ◌F  ○M   ◌F  ○M
─────── 중앙 ───────                    ◌M       ◌M      ◌ = 뚫린 우리 선수 (공 뒤)
 우리 FW  FW                      Z1  ◌D  ○F      ◌D     ○F = 패스 후보
 우리 MF  MF                         ▓▓▓▓ ⚽○F ▓▓▓▓▓▓    공: 우리 박스 (빨강 점멸)
 우리 DF  DF   (강조만 됨)                  ●G           우리 골
```

v0.3에서는 공이 어디 있는지 "상대 슛 vs 우리 GK"라는 글자로만 알 수 있었다. v0.4에서는 공이 우리 골 앞에 있고, 우리 필드 선수 6명이 전부 공 뒤로 따돌려졌고, 남은 건 GK 하나라는 게 그림으로 보인다.

### 9.1 기본 규칙

- 7인제: GK 1 + 필드 6 (포메이션 8.2절).
- 경기 = N포제션 (친선 6, 목표 8/10/12). 한 포제션 = 한 팀의 공격 시퀀스.
- 경기장은 세로 **5구역** (9.2절). 공은 항상 한 구역에 있고, 듀얼은 공이 있는 구역에서 일어난다.
- 공격 = 구역을 한 칸씩 전진: ① 빌드업 → ② 중원 → ③ 파이널 서드 → ④ 슈팅. 단계마다 그 앞을 막는 수비 라인과 1:1 듀얼.
- 교체 없음 **[가정]** → 피지컬 스탯의 가치.

### 9.2 경기장 5구역 ★

화면 방향은 고정: **우리 골은 항상 아래**, 우리는 위로 공격한다. "공이 아래로 내려올수록 위험"이 직관이 되게.

| 구역 | 이름 | 우리 공격일 때 | 상대 공격일 때 |
|---|---|---|---|
| Z5 | 상대 박스 | ④ 슈팅 (vs 상대 GK) | — |
| Z4 | 상대 진영 | ③ 파이널 서드 (vs 상대 DF) · 중거리 슛 가능 | ① 상대 빌드업 (vs 우리 FW) |
| Z3 | 중원 | ② 중원 돌파 (vs 상대 MF) | ② 중원 돌파 (vs 우리 MF) |
| Z2 | 우리 진영 | ① 우리 빌드업 (vs 상대 FW) | ③ 파이널 서드 (vs 우리 DF) · 중거리 슛 가능 |
| Z1 | 우리 박스 | — | ④ 슈팅 (vs 우리 GK) |

- 단계 ①~④는 기존 규칙의 라인 순서(상대 FW → MF → DF → GK)와 1:1로 대응한다.
- 구역으로 다시 쓴 규칙 (v0.4 기준. v0.5 수비 손익은 9.8절):
  - **슛**: 박스(④)에서 정상 슛. 파이널 서드(③)에서는 중거리 슛(계수 적용).
  - **버티기**: 전 구역에서 선택 가능. 파이널 서드에서는 중거리 슛도 막는다 (기존 블록 역할, 9.8절).
  - **역습: 공을 뺏은 그 구역에서 반대 방향 공격이 시작된다.** (v0.5 예외: 인터셉트로 뺏으면 한 구역 앞에서, 버티기로 뺏으면 자기 빌드업에서. 상한·스틸은 9.8절) 예: 우리가 빌드업(Z2)에서 뺏기면 상대는 Z2, 즉 상대의 파이널 서드에서 시작해 바로 우리 DF와 붙는다. "높은 곳에서 잃으면 위험하다"가 규칙 설명 없이 그림으로 이해된다. "스틸" 계열 스킬은 한 구역 더 전진.
  - **세이브 후 골킥 · 골 후 킥오프**: 공을 넘겨받은 팀이 자기 빌드업 구역(①)에서 시작.

### 9.3 팀 모양 — 선수들이 공을 따라 움직인다 ★

매 듀얼(비트)마다 14명 전원의 위치를 아래 규칙으로 다시 계산하고, 선수들이 새 위치로 달려간다.

**수비 팀**
1. 아직 뚫리지 않은 라인: 공과 자기 골대 사이에 순서대로 선다.
2. 지금 듀얼하는 수비수: 공 바로 앞(골대 쪽)으로 나와 공 가진 선수와 마주본다. 같은 라인의 나머지는 옆에서 커버한다 (커버 보너스 표시).
3. **이미 뚫린 라인: 공 뒤에 그린다** (반투명 + 추격 방향 표시). 그래서 공과 골대 사이에 남은 선수 수 = 남은 듀얼 수. "골까지 남은 벽"이 눈으로 보인다.
4. GK는 항상 자기 골문 앞.

**공격 팀**
1. 공 가진 선수: 공 위치.
2. 다음 단계에서 패스를 받을 동료: 공보다 한 구역 앞, 패스가 도착하는 구역 안 (패스 후보 표시).
3. 나머지: 공 뒤에서 받친다. 공격이 올라갈수록 DF 라인도 하프라인까지 따라 올라온다.
4. GK는 항상 자기 골문 앞.

**가로 배치**: 라인 인원수대로 좌우 균등 (1명 중앙 / 2명 30·70% / 3명 20·50·80%). 듀얼 수비수는 공 가진 선수의 레인으로 이동한다. 가로 위치는 연출일 뿐 규칙에는 쓰지 않는다 **[가정]**.

**초안 좌표** — 세로 위치(%), 공격 방향 기준 (0 = 공격 팀 골문, 100 = 상대 골문). 상대 공격이면 화면에는 100에서 뺀 값으로 그린다.

| 단계 | 공 | 공격 GK | 공격 DF | 공격 MF | 공격 FW | 수비 FW | 수비 MF | 수비 DF | 수비 GK |
|---|---|---|---|---|---|---|---|---|---|
| ① 빌드업 | 28 | 4 | 26 | 46 | 60 | **32 듀얼** | 52 | 70 | 96 |
| ② 중원 | 50 | 6 | 34 | 52 | 68 | 42 뚫림 | **54 듀얼** | 72 | 96 |
| ③ 파이널 서드 | 72 | 8 | 44 | 62 | 78 | 58 뚫림 | 64 뚫림 | **76 듀얼** | 96 |
| ④ 슈팅 | 90 | 10 | 50 | 70 | 86 | 68 뚫림 | 78 뚫림 | 86 뚫림 | **97 듀얼** |

- 공 가진 선수는 자기 라인 좌표 대신 공 좌표에 선다.
- 패스 후보는 표 좌표가 공과 같은 구역이면 도착 구역 시작 + 2에 선다 (③ 단계 FW 후보 78 → 86, 상대 박스). 화살표 끝과 "상대 박스 진입" 문구가 같은 구역을 가리키게.
- 구역 경계 (우리 골 기준 %): Z1 0~16 / Z2 16~40 / Z3 40~60 / Z4 60~84 / Z5 84~100. 표의 공 좌표는 항상 해당 단계의 구역 안에 들어간다.

### 9.4 움직임 연출 (비트)

한 번의 듀얼 = 한 비트: **재배치**(선수들이 새 위치로 달려감) → **성향 표시·결정** → **액션 연출** → **결과 한 줄**.

| 결과 | 연출 |
|---|---|
| 드리블 성공 | 공 가진 선수가 수비수를 스쳐 다음 구역으로 달린다. 수비수는 뒤로 처지며 반투명 |
| 드리블 실패 (태클) | 수비수가 몸을 날려 공을 뺏는다 → 짧은 정지 → 양 팀이 역습 모양으로 재배치 |
| 패스 성공 | 공이 받는 선수에게 날아간다 (궤적 표시). 받는 선수 강조 |
| 패스 실패 (인터셉트) | 공이 궤적 중간에서 수비수에게 끊긴다 |
| 슛 → 골 | 공이 골망으로. 필드 플래시 + 세리머니. 킥오프 모양으로 재배치 |
| 슛 → 세이브 / 버티기 | GK 다이브, 또는 수비수 몸에 맞고 튕김 |
| 크로스 → 헤더 (v0.5) | 공이 포물선으로 박스에 떨어지고, 받는 선수가 뛰어올라 헤더 |
| 연계 발동 (v0.5) | "킬패스!", "원터치!", "헤더!", "침투!" 짧은 문구 |
| 태클 실패 (v0.5) | 수비수가 넘어져 잠깐 누운 모습 (제쳐짐) |
| 필살기 | 컷인 배너 1초 → 해당 액션 연출 |

- 시간 (1x): 액션 0.8초 + 재배치 0.65초 + 결과 0.95초 ≈ **비트당 2.4초**. 2x(비트당 1.2초)·4x는 비례 단축. 자동 1x 경기 40~60초 유지 **[검증]**.
  - v0.2 구현 검증: 처음 잡은 비트당 1.2초로는 자동 1x 목표 경기(8포제션)가 중앙 23초, 친선(6포제션)이 16초에 끝나 목표에 못 미쳤다. 2.4초로 늘려 목표 경기 중앙 약 42초(10~90%: 29~67초), 친선 약 31초.
  - 결과 한 줄은 다음 비트가 시작되면 걷는다 (지난 결과가 새 연출 위에 남지 않게).
- "결과 스킵"은 연출 없이 최종 스코어로 바로.

### 9.6 결정 화면 (수동 개입)

결정을 기다릴 때 "이 선택에 무엇이 걸려 있는지"를 필드 위에 보여준다.

- **성향** (v0.5, 의도 표시 대체): 성향은 9.9절.
  - 필드: 상대 듀얼 선수 머리 위에 아이콘 + 색 막대로 **상위 2개**만 (예: 🦶65 ➡35). 숫자 전체는 정보 줄에 텍스트로.
  - 정보 줄 오른쪽에 우리 듀얼 선수의 성향을 작게 — "자동이면 우리 선수가 이 확률로 고른다"는 뜻이다. AI는 상대 성향을 보지 않는다.
  - 상대의 실제 선택은 보이지 않는다 (간파 제외, 9.11절).
- **액션 버튼**: 제목 줄에 액션 이름 + 기대 %, 아래 두 줄에 성공 / 실패 결과 (짧은 형식, 한 줄 15자 안팎).
  - 공격 예: "드리블 41%" / "성공 박스 진입" / "실패 상대 빌드업"
  - 수비 예: "태클 48%" / "막으면 역습(중원)" / "뚫리면 제쳐짐 +25%"
  - 기대 %는 상대 성향 확률로 가중한 값 **[가정]**. 수비는 막을 확률, 공격은 돌파 확률. **파이널 서드 공격 버튼은 "이번 공격 득점 기대"(돌파 × 이후 슛)로 통일** — 중거리 슛(바로 골)과 드리블(박스 진입)의 %를 같은 기준으로 비교하기 위해. 손익이 다르므로 %가 가장 높은 버튼이 항상 정답은 아니다.
- **배치**: 공격은 켜진 액션만 **2×2 그리드**(버튼 높이 약 51px), 수비는 3열. 결정 대기 중 로그는 3줄. 이 조합으로 390×844에서 필드 56%를 유지하고 스크롤 없음 (v0.2 화면 실측 기준).
- **화살표**: 버튼을 누르고 있으면(모바일) 또는 올리면(PC) 필드에 표시 — 드리블 = 전진 화살표, 패스 = 받는 선수까지 점선, 크로스 = 받는 선수까지 포물선, 슛 = 골문까지.
- **패스 받을 선수 고르기** (v0.5): 받을 수 있는 동료가 2명 이상이면 패스·크로스 버튼 제목에 받는 선수가 붙는다 ("패스 → 그룸바▾ 38%"). 기본값은 9.10절 규칙의 최고 선수. 바꾸려면 **필드의 후보 토큰을 탭**한다 (후보 전원이 도착 구역에 그려진다). 결정 중 토큰 탭 = 받는 선수 선택, 길게 누르기 = 미니 카드. 받는 선수는 액션별(패스·크로스 각각) 기본값을 가지며, 스킬로 도착 라인이 바뀌면 기본값으로 돌아간다. 후보가 1명이면 표시만.
- 받는 선수는 결정적으로 정해진다(무작위 없음). 미리보기와 실제가 달라지면 안 된다.
- **정답 고정 비트** **[가정]**: 한 선택지가 상대의 어떤 선택에 대해서도 최선(차이 2%p 미만)이면 수동 개입 중에도 멈추지 않고 자동 처리하고 필드에 "정답 고정"을 잠깐 띄운다. 수동 결정은 실제로 갈림길인 비트에만 남는다 (라인·스탯 구조상 MF 라인 수비처럼 답이 고정되는 비트가 많다 — 9.8절).
- **간파**: 간파 스킬이나 간파 사용권(9.11절)이 있으면 스킬 줄에 뜬다. 쓰면 상대의 이번 선택이 확정 공개되고 결정 대기가 유지된다. 상대가 먼저 간파를 쓴 듀얼이면 우리 간파는 비활성, 성향 막대 자리에 "상대가 우리 수를 읽는 중", 기대 %는 "상대가 짝을 맞춘다" 기준으로 다시 계산.

### 9.8 듀얼 (v0.5 개편)

> v0.5 변경 근거 (프로토타입 v0.2 측정): 수비 3종은 "상대 공격과 짝이 맞으면 ×1.5" 외에 아무 차이가 없었다. 블록은 파이널 서드에서만 쓸 수 있었고 AI가 사실상 고르지 않아(시즌 1·2 0%) 죽은 선택지였다. 시즌 2는 설계상 2지선다였지만 정찰·수첩 같은 공개 +1 효과가 겹쳐 실제로는 확정 공개였고, 시즌 3은 찍기(의도 표시를 따라도 무작위와 승률 차이 없음)였다. → 수비 액션마다 쓰는 스탯과 손익을 다르게 하고, 의도 공개를 성향(9.9절)으로 바꾼다.

**공격 액션**

| 공격 | 스탯 | 어디서 | 성공 시 | 짝이 맞는 수비 |
|---|---|---|---|---|
| 드리블 | 드리블 | 전 구역 | 같은 선수가 다음 구역으로 (체력 소모 큼) | 태클 |
| 패스 | 패스 | 받을 동료가 있을 때 | 고른 동료가 다음 구역에서 받음, 연계 +1. 박스 도착이면 원터치 슛으로 (9.10절) | 인터셉트 |
| **크로스** (신규) | (패스+드리블)/2 | 파이널 서드, **크로서 특성 선수만** | 고른 동료가 박스에서 받아 **헤더**로 마무리 (다음 듀얼 = 헤더 vs GK), 연계 +1 | 인터셉트 |
| 슛 | 슈팅 (헤더는 (슈팅+피지컬)/2) | 박스 = 정상 슛, 파이널 서드 = 중거리 (계수 0.6 **[가정]**, v0.4 1.0에서 하향) | 골 | 버티기 (파이널 서드) / GK |

- 크로스 받을 후보 = FW 전원 + MF 중 피지컬 최고 1명 (공 가진 선수 제외). 패스(같은 라인 FW만)와 후보가 달라 선택이 생기고, 원톱(2-3-1)도 MF에게 크로스할 수 있다. 후보 전원은 박스(Z5 시작 + 2)에 그린다.
- 중거리 슛 계수를 내린 이유: 1.0이면 파이널 서드 중거리(한 번 이기면 골)가 드리블·패스로 박스에 들어가 GK와 붙는 경로보다 득점 기대가 높아 지배 전략이 됐다 (간이 모델: "무조건 중거리" 수동이 자동 대비 +6~12%p).

**수비 액션** — 셋 다 전 구역에서 선택 가능. GK 듀얼은 세이브 자동.

| 수비 | 스탯 | 짝 맞히기 | 막으면 | 뚫리면 |
|---|---|---|---|---|
| **태클** (몸싸움) | (수비+피지컬)/2 | 드리블을 읽으면 ×1.5, **빗나가면 ×0.8** | 그 자리에서 역습 (기본 역습 위치) | **제쳐짐**: 상대의 바로 다음 듀얼 공격력 +25%, 그 듀얼 우리 커버 보너스 0 (다음이 GK면 +25%만) |
| **인터셉트** (길목) | (수비+패스)/2 | 패스·크로스를 읽으면 ×1.5, **빗나가면 ×0.8** | **빠른 역습**: 한 구역 앞에서 시작 | 상대의 바로 다음 듀얼 공격력 +10% |
| **버티기** (블록 대체) | 수비 | 없음 (×1.0). 파이널 서드에서 중거리 슛이면 ×1.5 | 공을 뺏지만 **역습 이점 없음** (우리 빌드업부터) | 추가 손해 없음 |

- 결정 구조: 태클·인터셉트는 짝을 노리는 도박(맞히면 ×1.5, 빗나가면 ×0.8), 버티기는 수비 스탯 그대로의 안전한 선택. 예 (수비 700 · 피지컬 600 · 패스 400): 태클은 상대 드리블 성향이 약 40% 이상이면, 인터셉트는 상대 패스 성향이 약 68% 이상이면 버티기보다 기대값이 높다. 이기고 있으면 버티기, 지고 있으면 태클로 도박하는 판단이 생긴다.
- 버티기를 ×1.2가 아니라 ×1.0으로 둔 이유: ×1.2면 가장 높은 '수비' 스탯에 조건 없는 배율이 붙어, DF 라인에서 짝을 100% 맞힌 인터셉트보다도 강했다 (패스 < 0.6 × 수비인 수비수 전원 — 데이터의 DF 전부). 빗나감 ×0.8은 짝 노리기에 대가를 줘서 "애매하면 버티기"를 실제로 참으로 만든다.
- 구조상 한계: 액션별 수비 스탯과 공격 성향이 같은 스탯에서 나오므로 라인마다 정답이 고정되는 비트가 많다 (간이 모델: MF 라인은 인터셉트가 거의 항상 최선). 이런 비트는 9.6의 "정답 고정"으로 자동 처리하고, 수동 결정은 FW·DF 라인처럼 실제 갈림길에 남긴다.
- **역습 시작 위치** = §7.5 기본 (FW 라인에서 뺏음 → 상대 DF 라인 공략 / MF → MF / DF·세이브 → 빌드업) + 인터셉트 1 + 스틸 스킬 1, **상한 2** (박스에서 시작하지 않음). 상한에 걸려 이점이 없으면 대신 텐션 +10 **[가정]**. 버티기로 뺏으면 항상 빌드업(0)이고 스틸도 무시(AI는 버티기일 때 스틸을 쓰지 않는다). 빠른 배급(9.10절)은 세이브 후에만 +1.
- 수치(×1.5 / ×0.8 / +25% / +10% / 0.6)는 전부 **[가정]**, 시뮬로 맞춘다.
- 판정식:

```
공격력 = 스탯 × 액션 계수 × 스타일 상성 × 컨디션 × 체력 보정 × 적성 × 스킬 × (1 + 연계 보너스 합, 상한 +60%) × (extraLine 슛 +20%)
수비력 = 액션별 스탯 × 스타일 상성 × 컨디션 × 체력 보정 × 적성 × 스킬 × (1 + 커버 0.1/명)
         × (짝 맞힘 1.5 | 빗나감 0.8 | 버티기 1.0 · 중거리 상대 1.5)
GK 세이브 = 수비 × 세이브 계수 × (원터치면 0.85)
성공률 = 공격력 / (공격력 + 수비력)      ※ 최소 10%, 최대 90%
```

연계 보너스 합 = 연계 특성 + 연계 스택(+10%/개) + 제쳐짐(+25%) + 인터셉트 뚫림(+10%) — 더해서 한 번 곱한다 **[가정]**.

### 9.9 성향과 자동 선택 ★ (v0.5, 의도 표시 대체)

**성향** = 선수가 각 액션을 고를 확률. 스탯으로 정해지고, 무엇을 눌렀는지에 따라 바뀌지 않는다. 시즌과도 무관하다. AI는 상대의 버릇에 적응하지 않는다.

- **성향값 = 그 액션의 판정값** (짝 맞힘·빗나감 제외): 스탯 × 액션 계수 × 전술 보정 × 연계 특성 보정. 버티기 = 수비 × 1.0 (철벽이면 × 1.15). 판정에 쓰는 힘과 고르는 경향이 같다 — "자기 스탯이 높은 액션으로 밀고 간다".
- **지배된 선택지는 성향 0**: 짝을 맞혀도(×1.5) 다른 선택지의 기본값보다 약하면 고르지 않는다. 예: 수비 900 · 패스 300인 DF의 인터셉트(짝 900)는 버티기(900)를 넘지 못하므로 0.
- 확률 = 성향값³ / Σ 성향값³ (지수 3 **[가정]**). 스탯 차이가 클수록 한쪽으로 뚜렷해진다.
  - 예: 드리블 600 / 패스 400 → **드리블 77 · 패스 23**. 드리블 520 / 패스 500 → 53 · 47.
  - 예 (수비 700 · 피지컬 600 · 패스 400): 태클 650 / 인터셉트 550 / 버티기 700 → **버티기 44 · 태클 35 · 인터셉트 21**.
  - 지수는 사용자 원안("스탯 높은 액션으로 밀고 간다")과의 거리를 조절하는 손잡이다. 올리면 1위 액션에 더 몰린다 (지수 6이면 600 / 400 → 92 · 8).
- **전술 보정**: 공격·수비 성향 지시는 해당 액션 성향값(세제곱 전)에 ×1.15 **[가정]** (확률로는 약 +10%p). 슛 타이밍: "라인 다 뚫고" = 중거리 성향 0, "기회 보이면 중거리" = 중거리 ×1.15. 텐션 사용 지시는 스킬(간파 등)의 AI 발동 시점에만 쓴다.
- **체력**: 전 스탯에 같은 배율을 곱하는 효과(체력 20% 이하 −20%, 적성)는 판정에만 들어가고 성향 비율은 바꾸지 않는다. 대신 **체력 20% 이하면 드리블 성향값 ×0.7, 패스·크로스 ×1.2** **[가정]** — 지치면 체력 소모가 큰 드리블을 피한다.
- **자동 (우리 팀·상대 AI 모두 같은 규칙)**: 성향 확률대로 액션을 뽑는다 (rng 1회). 상대를 읽지 않는다. v0.4의 "상대 AI가 우리 자동 AI의 선택을 예측해 막는" 로직은 삭제한다. 패스 받을 선수는 9.10절 규칙 (상대 정보 미사용).
- **수동**: 상대 성향을 보고 고른다. 상대의 실제 선택은 모른다. 확정 정보는 간파(9.11절)로만.
- 수동의 기대 이득 5~10%p 목표 **[검증]**. 간이 모델 추정 (버티기 ×1.0 · 빗나감 ×0.8 · 중거리 0.6 반영): 버튼의 기대 %만 보고 고르는 수동이 자동 대비 +5~7%p.

**A안(항상 1위 액션)이 아니라 B안(성향 %대로)인 이유**

사용자 원안은 "자동이면 자기 스탯이 높은 액션으로 밀고 간다"였고, "개입 없는 PvP(등록 팀끼리 자동 대결)에서는 어느 쪽이 유리한가"를 비교해 추천안 B로 진행했다 (**확인 필요**). B에서도 성향값 = 판정값이고 지배된 선택지는 0이라, 강한 액션을 주로 고르는 원안의 성격은 유지된다.

보조 근거 — 개입 없는 PvP 비교. 자동 육성 등록 팀 30개(무작위 편성·전술), 팀 쌍마다 200경기. 태클·인터셉트의 액션별 스탯만 v0.5를 반영했고, 버티기와 손익은 이전 규칙인 간이 모델이다.

| 지표 | A 항상 1위 | B 성향 %대로 (지수 3) | B (지수 6) |
|---|---|---|---|
| 팀 전력과 순위의 상관 | 0.64 | 0.55 | 0.58 |
| 약팀(전력 5% 이상 낮음) 승률 | 38% | 40% | 40% |
| 가위바위보식 순환 관계 | 0% | 0% | 0% |
| 상대 5팀 중 골라서 얻는 이득 | +10.6%p | +9.4%p | +9.9%p |
| 훈련 1~2번 차이로 인한 승률 변화 (최대) | 2.0%p | 1.8%p | 4.2%p |

- **PvP에서는 차이가 작다.** A가 전력이 순위를 조금 더 결정한다(상관 0.64 vs 0.55). 가위바위보식 상성 편성이나 "훈련 한두 번으로 승패가 뒤집히는" 문턱 문제는 어느 쪽에서도 나타나지 않았다. 한 경기에 여러 선수가 라인마다 번갈아 붙어 효과가 평균으로 묻히기 때문이다.
- **결정 기준은 수동 플레이다.** A면 성향 막대가 곧 상대의 확정된 답이 되어 "확정 공개는 간파로만"이 무너진다. 측정에서 상대 선택을 알고 고르는 수동은 시즌 3 공격 승률 56%, 자동은 30%였다 (26%p 차이, 목표 5~10%p).
- v0.5 규칙으로 구현한 뒤 재측정한다.

### 9.10 연계 ★ (v0.5)

> v0.5 측정: 기존 연계(패스 성공마다 슛 위력 +10%)는 골 성공률을 올리지 못했다 (연계 0 → 67%, 1 → 60%, 2 → 71%, 3 → 55%). 오히려 패스로 박스에 들어온 슛(58%)이 드리블로 들어온 슛(69%)보다 골이 적었다. 파이널 서드 패스가 같은 라인의 다른(대개 약한) FW에게 가기 때문이다. → "누가 누구에게 연결하느냐"가 의미를 갖게 바꾼다.

**1. 연계 특성** — 캐릭터마다 1개, 뽑을 때부터 보유 (7.1절). 수치 **[가정]**.

| 특성 | 효과 | 프로토타입 배정 |
|---|---|---|
| 킬패스 | 이 선수의 패스를 받은 선수의 첫 듀얼(드리블·패스·크로스·박스 슛·헤더) +20%. 중거리 제외 | 실루엔 (엘프 MF) |
| 크로서 | 파이널 서드에서 크로스 사용 가능, 크로스 +10% | 울릭 (늑대 FW) |
| 타깃맨 | 크로스를 헤더로 마무리하면 +25% | 그룸바 (거인 FW) |
| 침투 | 패스를 받은 직후 드리블 +15% (받고 바로 돌파) | 타린 (인간 MF) |
| 볼 운반 | 드리블 체력 소모 −30%, 빌드업 구역 드리블 +10% | 미르카 (고양이 MF/FW) |
| 철벽 | 버티기 ×1.0 → ×1.15 | 돌바르 (드워프 DF) |
| 빠른 배급 | 세이브 후 역습이 빌드업이 아니라 중원에서 시작 | 네리아 (정령 GK) |
| 주장 | 팀워크 증폭 단계를 계산할 때 팀워크 +10 | 아르덴 (인간 DF) |
| 피니셔 | 패스·크로스를 받은 직후의 박스 슛·헤더 +15% | 런치 캐릭터용 (프로토타입 미배정) |

- **제안 대비 변경 (확인 필요)**:
  - 원투 → 침투. 라인 돌파 구조에서는 패스한 선수가 공을 다시 받을 수 없다.
  - 피니셔는 프로토타입에 배정하지 않는다. 그룸바는 타깃맨이 되어 울릭(크로서)과 센터링 조합을 이룬다. FW 슈팅이 약한 미르카에게는 효과가 없다.
  - 볼 운반은 미르카 그대로다.
  - "캐릭터마다 1개"를 DF·GK까지 채우려고 철벽, 빠른 배급, 주장을 추가했다.
  - 킬패스는 "바로 슛"에서 "받은 선수의 첫 듀얼"로 바꿨다. MF 킬패서의 패스는 파이널 서드에서 받게 되므로, "바로 슛"이면 약한 중거리밖에 되지 않는다.
- **판정 조건**: "받은 직후" = 받은 선수의 첫 듀얼. 특성의 성향값 보정 = 자기 액션에 붙는 효과와 같은 배율 (크로서 +10% → 크로스 성향값 ×1.1, 침투 → 받은 직후 드리블 ×1.15). 남의 슛에 붙는 특성(킬패스·타깃맨)은 성향 보정 없음.
- 상대 팀 선수에게도 특성을 준다 (PvE 밸런스가 PvP와 같은 기준이 되게). 런치 20명은 공격 특성과 수비·빌드업 특성을 섞어 배분하고, 같은 특성 여러 명 가능.

**2. 원터치 슛** (모든 선수 공통 규칙): 패스·크로스로 박스(④)에 도착한 뒤의 첫 슛·헤더는 GK 세이브 ×0.85. 라인 브레이커로 박스에 들어온 경우도 포함하고, extraLine +20%와 곱한다. 패스로 박스에 넣는 것이 드리블보다 손해이던 문제를 바로잡는다.

**3. 크로스 → 헤더**: 크로서가 파이널 서드에서 박스로 공을 띄운다 (인터셉트가 짝). 성공하면 고른 받는 선수가 헤더(슈팅+피지컬)/2로 GK와 붙는다 — 원터치 적용, 타깃맨이면 +25%. 슈팅이 약해도 피지컬이 강한 선수가 득점원이 된다. 크로스 성공도 연계 +1.

**4. 패스 받을 선수**: 규칙 = 받는 선수가 도착 구역에서 쓸 **주 액션의 판정값**(스탯 × 계수 × 적성 × 연계 특성·원터치 보정)이 가장 높은 선수. 상대 정보는 쓰지 않는다. 동률이면 슬롯 순서. 자동과 수동의 기본값이 이 규칙이고, 수동은 후보가 2명 이상이면 직접 바꿀 수 있다 (9.6절). "킬패스를 타깃맨에게" 같은 연결을 직접 설계할 수 있다.

**5. 팀워크 증폭** (v0.3의 "연계기 해금"을 대체): 팀워크 60 / 80 / 100에서 연계 특성 효과 ×1.1 / ×1.2 / ×1.3 **[가정]**.
- 가산 부분에만 곱한다 (+20% × 1.3 → +26%).
- 사용 조건형(크로서의 크로스 가능), 위치형(빠른 배급), 철벽, 주장은 증폭하지 않는다.
- 처음 안 ×1.25 / ×1.5 / ×2는 줄였다. 시즌 3·등록 팀은 거의 전부 팀워크 80 이상이라, 증폭이 사실상 상시 기본값이 됐기 때문이다.

**6. 연계 스택** (패스·크로스 성공마다 +10%)은 유지하되 연계 보너스 합(9.8절 판정식)에 들어간다. 주된 효과는 특성·원터치가 담당한다.

**7. 연출**: 연계가 터지면 짧은 문구 — "킬패스!", "원터치!", "헤더!", "침투!". 크로스는 포물선 궤적.

### 9.11 간파 — 유일한 확정 공개 ★ (v0.5)

- **효과** — 단순 공개만으로는 가치가 작았다 (간이 모델에서 수비 0.2~2%p, 공격 0~1.5%p). 성향이 스탯으로 뚜렷하게 쏠려 있어 모르고 골라도 대부분 맞기 때문이다. 그래서 공개에 힘을 더한다:
  - **수비 간파**: 상대의 이번 선택을 확정 공개 + 이번 듀얼에서 짝을 맞히면 ×1.5 대신 **×2.0**.
  - **공격 간파**: 상대의 이번 선택을 확정 공개 + 이번 듀얼에서 **상대의 짝 맞힘 무효**.
  - 간이 모델에서 수비 간파 1회의 가치가 약 4~9%p가 된다 **[검증]**.
- **사용**: 사람이 쓰면 공개된 상대 선택을 보고 고른다 (결정 대기 유지). AI 순서: 성향 추첨(rng 1회) → 스킬 결정 → 판정 때 교체. 수비는 공개된 공격에 막을 확률이 가장 높은 액션(버티기 포함), 공격은 성공 확률이 가장 높은 액션. 추가 난수 없음 — 같은 seed 같은 결과.
- **쓸 수 있는 곳**: line 0~2 듀얼만. 박스(④)는 슛·GK 세이브뿐이라 선택지가 없다 (버튼 비활성, 사유 표시).
- **비용**: 텐션 40~50 **[가정]**. AI 사용 시점: 수비용 = 파이널 서드 수비 듀얼, 공격용 = 파이널 서드 공격 듀얼. 둘 다 동점·열세의 마지막 포제션들 우선.
- **양쪽 모두 쓰는 경우**: 먼저 쓴 쪽만 효과. 상대가 먼저 썼으면 우리 간파 버튼 비활성 (9.6절).
- **보유**: 기존 '매의 눈'(sk_eagle_eye, 수비용)을 기본으로, 공격용 간파 1종 신설, 일부 SSR 고유 스킬과 서포트 카드 힌트로 추가. 스킬 슬롯 3칸의 가치가 올라간다.
- **간파 사용권** — 스킬이 없어도 1회 쓸 수 있는 권리. 간파를 올려주던 기존 콘텐츠를 스킬 보유와 무관하게 작동하도록 바꾼다:
  - 유물 '감독의 수첩'(rl_coach_notebook): 경기마다 간파 사용권 1회 (텐션 0). 간파 스킬이 있으면 비용 −50%.
  - '연맹컵 결승 전야'(ev_prematch_s2)의 정찰 선택지: 이번 경기 간파 사용권 1회.
  - '조약 감독관 방문'(ev_treaty_inspector): 이번 시즌 경기마다 간파 사용권 1회.
- **시즌 3 보스 팀**이 간파를 가진다 — "우리 수를 정확히 읽는 팀"이라는 성격. 다만 간파로 움직이는 승률은 −2~3%p 수준이라, 시즌 3 난이도는 상대 스탯·연계 특성으로 맞춘다.

### 9.14 텐션 · 경기 체력

- 텐션: 팀 게이지. 듀얼 성공 +10, 스틸·세이브 +15, 골 +20. 액티브·필살기 비용 30~50, 간파 40~50. 전술 "텐션 사용"이 AI의 시점을 정한다.
- 경기 체력: 선수별(훈련 체력과 별개). 드리블 −8, 패스·크로스 −4, 슛 −5, 수비 −4. 피지컬이 높을수록 덜 소모. 20% 이하면 전 스탯 −20% (판정), 성향은 9.9절의 체력 규칙.
- 연계는 9.10절로 옮김.

### 9.15 자동 · 수동 · 길이

- **자동이 기본.** 양 팀 모두 성향 확률(9.9절) + 스킬 발동 조건으로 고른다. 배속 1x/2x/4x (1x = 비트당 2.4초, 2x = 1.2초)와 결과 스킵.
- **수동 개입:** "개입" 버튼 → 다음 결정 비트에서 재배치까지 보여준 뒤 멈춤 (정답 고정 비트는 멈추지 않음) → 성향·결과 미리보기(9.6절)를 보고 액션·받는 선수·스킬 선택. 수동의 기대 이득 5~10%p 이내 **[검증]**.
- 길이: 친선 6포제션, 목표 8/10/12. 자동 1x 40~60초 (목표 경기 기준, 친선은 약 30초), 수동 2~3분. 런당 3~5경기.
- 동점: 친선은 무승부. 목표 경기는 연장 2포제션 → 승부차기 5개 → 서든데스. 승부차기는 박스만 확대해 키커와 GK만 표시.
- PvE·PvP는 양쪽 AI. **결정적 시뮬레이션**(시드 고정) → 리플레이 가능. 리플레이도 같은 비트 연출로 재생된다.

## 10. 로그라이크 요소

### 10.1 런 내 랜덤성
훈련 칸 배치(선수·서포트), 이벤트, 상대 팀 편성·스킬·원소, 루트 선택지, 유물 드롭. (v0.5: 성향은 스탯으로 고정이라 랜덤 요소가 아니다)

### 10.2 유물 (라커룸 아이템)
런 동안만 유지. 경계전 승리·루트·이벤트로 획득, 3개 중 1개 선택.

| 이름 | 효과 |
|---|---|
| 낡은 주장 완장 | 목표 경기에서 팀 컨디션 +1단계 |
| 짝짝이 축구화 | 드리블 성공 시 10% 확률로 경기 체력 +5 |
| 감독의 수첩 | 경기마다 간파 사용권 1회 (간파 스킬이 있으면 비용 −50%) (v0.5) |
| 금 간 트로피 | 훈련 효율 +15%, 휴식 효과 −30% |
| 조약의 인장 | 경계전 패배 시 보상 감소 절반 |

### 10.3 리그 등급 (런 난이도)
5부 → … → 1부 → 조약 리그. 결승 승리로 다음 등급 해금. 상위일수록 변이 규칙(부상률 증가, 상대 간파 스킬 추가, 유물 선택지 2개, 상대 공명 보유) + 평가 상한·클럽 포인트 상승. 등록 팀에 "몇 부에서 만들어졌는지"가 남는다.

## 11. 메타 진행 & 라이브 서비스

### 11.1 가챠

| 풀 | 내용 | 돌파(중복) 효과 |
|---|---|---|
| 선수 | R / SR / SSR | 스탯 상한·초기 스탯 ↑, 고유 스킬 Lv ↑, 2·4단계에서 부 포지션 적성 +1, 3단계에서 연계 특성 강화 **[가정]**, 종족 패시브 강화 |
| 서포트 카드 | R / SR / SSR | 훈련 보너스 ↑, 초기 유대 ↑, 힌트 확률 ↑, 레벨 상한 ↑, 고유 효과 해금 |

- 확률·천장 **[가정]**: SSR 3% / SR 15% / R 82%, 천장 200회. 픽업 배너 2주.
- 확률형 아이템 정보 공개 의무(국내 게임산업법) 준수.

### 11.2 플레이로 얻는 성장 (무료 축)

| 항목 | 획득 | 효과 |
|---|---|---|
| 클럽 포인트 | 런 결과 | 클럽 레벨 → 유물 풀, 이벤트 풀, 루트, 전술 슬롯, OB 코치 슬롯, 호출권, 리그 등급 |
| 선수 친밀도 | 기용 횟수 | 선수 스토리, 초기 팀워크 +소량 **[가정]** |
| OB 코치 (계승) | 등록 팀 선수 지정(최대 2) | 시즌 시작마다 인자: 같은 포지션 선수 스탯 ★, 스킬 힌트, **적성 ★** |
| 미션 | 일일·주간 | 무료 재화, 골드 |

가챠는 "누구를·얼마나 강하게", 플레이는 "무엇으로·어떤 조건에서". 새로운 것을 발견하는 재미는 무료 축에.

### 11.3 팀 등록
런 종료 시 7명 스탯·스킬 + 전술 + 평가를 등록 슬롯에 저장(3개 **[가정]**). PvE·PvP에서 그대로 사용. 개별 선수는 선수 명부에 남아 OB 코치 지정 가능.

### 11.4 챌린지 리그 (싱글 엔드게임)
1~50단계 **[가정]**, 단계별 고정 AI 팀(종족·국가 클럽), 5단계마다 보스. 등록 팀 + 전술로 자동 경기, 재도전 무제한. 클리어 보상 + 첫 클리어 보너스. 올라갈수록 상대 공명·특정 스킬 대응이 필요한 편성 퍼즐.

### 11.5 아레나 (비동기 PvP)
등록 팀 1개 업로드 → 비슷한 랭크의 다른 감독 팀 5개 중 선택 → 결정적 시뮬 → 랭크 포인트. 주간 시즌, 리그 등급·팀 평가로 매칭 구간 분리. 경기는 클라이언트 시뮬, 서버는 기록(부정 방지 13.2절).

자동 경기 규칙은 PvE와 같다: 양 팀 모두 성향 확률대로 고르고, 간파는 스킬 조건대로 AI가 쓴다. 개입 없는 PvP에서 "성향 %대로"와 "항상 1위"는 결과 지표 차이가 작았다 (9.9절 표, 항상 1위가 전력-순위 상관이 조금 높음) — 전력이 결과를 주로 결정하고, 가위바위보식 상성 편성이나 "훈련 한두 번으로 승패가 뒤집히는" 문턱 문제는 나타나지 않았다.

### 11.6 재화 · 행동력

| 재화 | 용도 | 획득 |
|---|---|---|
| 주얼 (무료/유료) | 가챠 | 미션, 런, 챌린지, 결제 |
| 골드 | 서포트 카드 레벨업 | 런, 아레나, 미션 |
| 클럽 포인트 | 영구 해금 | 런 결과 |

행동력 없음. 아레나는 일일 승리 보상 횟수만 제한 **[가정]**.

## 13. 기술

### 13.1 클라이언트
- Unity 2D (URP 2D, Pixel Perfect Camera), 세로 고정.
- 밸런스 데이터(스탯, 공식 계수, 이벤트, 스킬, 유물, 상대 팀)는 JSON → 웹 프로토타입과 공유, 서버 배포로 핫픽스.
- 경기 시뮬은 순수 로직 모듈(시드 RNG, 정수 연산). UI와 무관하게 돌아가야 PvP·리플레이·밸런스 테스트가 된다.

### 13.2 서버 (1인 · 서버 경험 없음 → BaaS)
직접 서버를 짜지 않는다. Unity Gaming Services / PlayFab / Firebase 중 하나 **(유니티 착수 전 결정)**.

| 서버에 둬야 하는 것 | 클라이언트에 둬도 되는 것 |
|---|---|
| 계정·인벤토리·재화, 가챠 뽑기(서버 함수), 결제 영수증 검증, 등록 팀 저장·조회, 아레나 매칭·랭킹 | 런 진행 전체, 경기 시뮬(런·PvE·PvP, 결정적 시드 → 결과·시드 보고) |

리스크: 등록 팀을 클라이언트가 만들어 조작 가능. 완화 — 평가·스탯 상한을 서버가 돌파 수로 검증, 이상치 탐지. 완전한 방지는 런치 이후.

### 13.3 웹 프로토타입
- Vanilla JS ESM, 빌드 없음, 아트 없음(색 원 + 이름). 코드는 버리고 데이터와 공식만 유니티로.

## 15. 리스크

- **1인 라이브 서비스**: 운영(배너·이벤트·CS·서버 비용)이 개발보다 큰 짐. 런치 스코프를 극단적으로 줄이고 자동화 가능한 운영만 남긴다.
- **7명 동시 육성의 인지 부하**: 훈련 칸 UI가 답. 못 읽히면 스탯 3종 축소 또는 자율 훈련 비중 상향.
- **경기 연출 시간 증가**: 비트 연출(1x 2.4초)로 경기가 길어질 수 있다. 20분 예산 안에서 배속·결과 스킵으로 흡수하고, 자동 1x 경기 40~60초를 넘으면 재배치·결과 시간을 먼저 줄인다.
- **패배해도 계속 → 긴장감 하락**: 평가 상한·보상 차이가 충분히 커야 한다. 수치 검증.
- **돌파 격차가 PvP 지배**: 매칭 구간 분리 + 편성 퍼즐(공명·상성·적성).
- **아트 물량**: 종족 공용 베이스 + 팔레트 스왑, 선수의 서포트 카드 재활용.
- **IP**: 레퍼런스는 시스템만. 캐릭터·이름·아트·UI 레이아웃은 독자적으로.
- **법규**: 확률 공개, 미성년자 결제 한도, 청약 철회 안내.

## 16. 결정 필요 사항 (다음 라운드)

1. **캐스트 구성과 타겟**: 전원 여성 캐릭터 / 혼성. 타겟 연령·성별.
2. **세계 이름, 종족 목록 확정, 감독의 스토리 훅**.
3. **서포트 카드의 정체**: 선수 재활용 + NPC 코치(7.7절 가정) vs 별도 캐릭터군.
4. **OB 코치(계승) 유지 여부**: 적성 ★가 붙어 역할이 생겼다. 유지 추천.
5. **스탯 5종 vs 3종**: 프로토타입에서 5종으로 시험 후 결정.
6. **컨디션 팀 단위 vs 선수 단위**.
7. **BaaS 선택**: Unity Gaming Services / PlayFab / Firebase.
8. **런치 스코프**: 챌린지 리그 단계 수, 아레나 시즌 길이, 배너 주기.
9. **프로토타입 피드백 후**: 훈련 수치, 경기 길이, 수동 이득 폭.
10. **가로 레인(좌·중·우)을 규칙으로 넣을지** (v0.4): 지금은 연출만. 넣으면 측면 돌파나 크로스 위치(측면에서만 크로스) 같은 전술이 생기지만 (크로스 자체는 v0.5에서 레인 없이 특성 액션으로 도입) 듀얼 판정과 AI가 복잡해진다. 추천: 보류.
11. **결과 미리보기 노출 범위** (v0.4): v0.2는 추천안(수동 개입 중에만)으로 구현. 확정 대기.
12. **비트 길이** (v0.4): 1x 비트당 2.4초 **[검증]** (1.2초는 자동 경기 16~23초로 짧아 v0.2 구현에서 늘림). 경기 체감 속도를 보고 조정.
13. **성향 지수** (v0.5): 3 **[가정]**. 높이면 성향이 뚜렷해져(읽기 쉬움) 특화형 선수가 예측 가능해지고, 낮추면 만능형처럼 흐릿해진다. 캐릭터 설계 축(특화형 vs 만능형)과 함께 정한다.
14. **버튼의 기대 성공률 표시** (v0.5): 표시(가정) vs 숨김. 표시하면 읽기 쉽지만 "가장 높은 % 누르기"로 흐를 수 있다 — 액션별 손익이 그 균형을 잡는지 프로토타입에서 확인.
15. **간파 비용·보유 범위** (v0.5): 텐션 40~50, 런치 스킬 중 몇 개에 넣을지.
16. **연계 특성 수치·런치 20명 배분** (v0.5). 프로토타입 배정과 제안 대비 변경(원투 → 침투, 피니셔 미배정, 철벽·빠른 배급·주장 추가) **확인 필요** (9.10절).
17. **자동 선택 B안** (v0.5): 사용자 원안(스탯 높은 액션으로 밀고 감)과 가까운 A안 대신 추천안 B로 진행 — **확인 필요**. 원안 쪽으로 옮기려면 성향 지수를 올린다 (9.9절).
18. **정답 고정 비트 자동 처리** (v0.5, 9.6절): 수동 중에도 답이 고정된 비트는 멈추지 않는다 **[가정]**. 직접 누르고 싶은지 확인.
19. **간파 강화 폭** (v0.5, 9.11절): 수비 간파 짝 ×2.0, 공격 간파 = 상대 짝 무효 **[가정]**.
